### **Exercise 1: Default Constructor**
1. Create a class named `Student` with the following attributes:
   - `String name`
   - `int rollNumber`

2. Write a default constructor that initializes `name` to `"Unknown"` and `rollNumber` to `0`.

3. In the `main()` method:
   - Create an object of the `Student` class using the default constructor.
   - Print the initialized values of `name` and `rollNumber`.

### **Exercise 2: Parameterized Constructor**

   - Print the initialized values.

## Here are the solutions to the exercises on **Constructors and Initialization Blocks** in Java:

---

### **Solution 1: Default Constructor**
```java
class Student {
    String name;
    int rollNumber;

    // Default Constructor
    Student() {
        name = "Unknown";
        rollNumber = 0;
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();
        System.out.println("Name: " + student.name);
        System.out.println("Roll Number: " + student.rollNumber);
    }
}
```

---

### **Solution 2: Parameterized Constructor**
```java
class Student {
    String name;
    int rollNumber;

    // Default Constructor
    Student() {
        name = "Unknown";
        rollNumber = 0;
    }

    // Parameterized Constructor
    Student(String name, int rollNumber) {
        this.name = name;
        this.rollNumber = rollNumber;
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student("Alice", 101);
        System.out.println("Name: " + student.name);
        System.out.println("Roll Number: " + student.rollNumber);
    }
}
```

---

### **Solution 3: Constructor Overloading**
```java
class Student {
    String name;
    int rollNumber;

    // Default Constructor
    Student() {
        this("Unknown", 0);
    }

    // Parameterized Constructor
    Student(String name, int rollNumber) {
        this.name = name;
        this.rollNumber = rollNumber;
    }

    // Overloaded Constructor
    Student(String name) {
        this(name, -1);
    }
}

public class Main {
    public static void main(String[] args) {
        Student defaultStudent = new Student();
        Student paramStudent = new Student("Alice", 101);
        Student overloadStudent = new Student("Bob");

        System.out.println("Default: " + defaultStudent.name + ", " + defaultStudent.rollNumber);
        System.out.println("Parameterized: " + paramStudent.name + ", " + paramStudent.rollNumber);
        System.out.println("Overloaded: " + overloadStudent.name + ", " + overloadStudent.rollNumber);
    }
}
```

### **Solution 7: Combining Static and Instance Blocks**
```java
class Student {
    static int totalStudents;

    static {
        totalStudents = 0;
        System.out.println("Static block executed");
    }

    {
        totalStudents++;
        System.out.println("Instance block executed");
    }
}

public class Main {
    public static void main(String[] args) {
        Student student1 = new Student();
        Student student2 = new Student();
        Student student3 = new Student();

        System.out.println("Total Students: " + Student.totalStudents);
    }
}
```

### **Solution 12: Singleton Class**
```java
class DatabaseConnection {
    private static DatabaseConnection instance;

    private DatabaseConnection() {
        // Private Constructor
    }

    public static DatabaseConnection getInstance() {
        if (instance == null) {
            instance = new DatabaseConnection();
        }
        return instance;
    }
}

public class Main {
    public static void main(String[] args) {
        DatabaseConnection db1 = DatabaseConnection.getInstance();
        DatabaseConnection db2 = DatabaseConnection.getInstance();

        System.out.println(db1 == db2); // Should print true
    }
}
```

### **Solution 13: Initializing Arrays in Constructor**
```java
class Team {
    String[] members;

    // Parameterized Constructor
    Team(int size) {
        members = new String[size];
    }

    void addMember(int index, String name) {
        members[index] = name;
    }

    void displayMembers() {
        for (String member : members) {
            System.out.println(member);
        }
    }
}

public class Main {
    public static void main(String[] args) {
        Team team = new Team(3);
        team.addMember(0, "Alice");
        team.addMember(1, "Bob");
        team.addMember(2, "Charlie");

        team.displayMembers();
    }
}
```
