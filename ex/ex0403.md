# Exercises

Here’s a set of exercises to help you understand the difference between **Pass by Value** and **Pass by Reference** in Java. Since Java uses **Pass by Value** for all variable types, these exercises will demonstrate how changes to primitives and objects are handled differently.

---

### **1. Pass by Value with Primitive Data Types**
1. **Exercise**: Create a program where you define a method `increment` that takes an `int` as a parameter and increments it by 1. Print the value of the variable before and after calling the method.

2. **Exercise**: Write a program with a method `doubleValue` that takes a `double` parameter, multiplies it by 2, and prints the result inside the method. Show that the original value outside the method does not change.

---

### **2. Pass by Value with Objects (Reference Behavior)**
3. **Exercise**: Create a class `Number` with a single field `value`. Write a method `incrementValue` that takes an instance of `Number` and increments its `value` field by 1. Show that the change persists outside the method.

4. **Exercise**: Write a class `Person` with a `name` field. Create a method `changeName` that takes a `Person` object and changes the `name` field. Demonstrate that the change persists outside the method.

---

### **3. Object Reassignment in Methods**
5. **Exercise**: Write a program where you pass an object of class `Person` to a method `reassignObject`. Inside the method, create a new `Person` object and assign it to the parameter reference. Show that the reassignment does not persist outside the method.

6. **Exercise**: Create a class `Car` with a `String` field `model`. Write a method `modifyCar` that tries to reassign the passed `Car` reference to a new object with a different `model`. Demonstrate that the reassignment does not persist outside the method.

---

### **4. Combination of Primitives and Objects**
7. **Exercise**: Write a program with a class `Rectangle` that has two fields: `length` and `breadth`. Create a method `scale` that multiplies `length` and `breadth` by a primitive factor passed to the method. Show that the changes persist for the object fields.

8. **Exercise**: Create a class `Account` with fields `balance` (primitive) and `accountHolder` (String). Write a method `updateAccount` that tries to modify both the `balance` and `accountHolder`. Demonstrate which changes persist and which do not.

---

### **5. Complex Behavior with Pass by Value**
9. **Exercise**: Write a program where you pass an object of class `Point` (with `x` and `y` fields) to a method `swapCoordinates`. Inside the method, swap the values of `x` and `y` and demonstrate that the changes persist outside the method.

10. **Exercise**: Create a class `Employee` with a `salary` field. Write a method `giveBonus` that adds a primitive bonus to the `salary`. Demonstrate that the change to the `salary` persists outside the method.

---

### **6. Method Chaining with Objects**
11. **Exercise**: Write a class `Book` with a `price` field. Write a method `updatePrice` that takes a `Book` object, modifies the `price`, and returns the same object. Demonstrate how method chaining can be used to update the price multiple times.

12. **Exercise**: Create a class `Student` with fields `name` and `grade`. Write a method `updateGrade` that modifies the `grade` and returns the same object. Use method chaining to update multiple `Student` objects in sequence.

---

### **7. Pass by Value and Immutability**
13. **Exercise**: Write a program where you pass a `String` to a method `appendText` that tries to add more characters to the `String`. Show that the original `String` remains unchanged.

14. **Exercise**: Create a class `BankAccount` with an immutable `String` field `accountNumber` and a mutable field `balance`. Write a method `updateAccountDetails` that tries to modify both fields and demonstrate the results.

---

### **8. Comparison of Behavior**
15. **Exercise**: Write a program that compares the behavior of modifying a primitive type (`int`) and modifying an object type (`Object`). Highlight how the changes persist differently for the two.

16. **Exercise**: Create a program with two methods:
   - One that modifies a primitive integer.
   - Another that modifies the field of an object.
   Demonstrate how Java’s pass-by-value mechanism affects the two scenarios.

---

These exercises are designed to clearly demonstrate the behavior of pass-by-value for primitives and the reference-like behavior for objects in Java. Let me know if you'd like solutions or further clarification!

# Solutions

Here are the solutions to the exercises on **Pass by Value vs Pass by Reference** in Java. These examples highlight how Java handles primitives and objects differently, even though all parameters are passed by value.

---

### **1. Pass by Value with Primitive Data Types**

1. **Increment Method**
   ```java
   public class PassByValueExample {
       public void increment(int number) {
           number++;
           System.out.println("Inside method: " + number);
       }

       public static void main(String[] args) {
           PassByValueExample example = new PassByValueExample();
           int num = 5;
           System.out.println("Before method: " + num);
           example.increment(num);
           System.out.println("After method: " + num); // Original value remains unchanged
       }
   }
   ```

2. **Double Value Method**
   ```java
   public class DoubleValueExample {
       public void doubleValue(double value) {
           value *= 2;
           System.out.println("Inside method: " + value);
       }

       public static void main(String[] args) {
           DoubleValueExample example = new DoubleValueExample();
           double val = 3.5;
           System.out.println("Before method: " + val);
           example.doubleValue(val);
           System.out.println("After method: " + val); // Original value remains unchanged
       }
   }
   ```

---

### **2. Pass by Value with Objects (Reference Behavior)**

3. **Increment Object Field**
   ```java
   class Number {
       int value;
   }

   public class IncrementObjectExample {
       public void incrementValue(Number num) {
           num.value++;
       }

       public static void main(String[] args) {
           Number number = new Number();
           number.value = 5;
           IncrementObjectExample example = new IncrementObjectExample();
           System.out.println("Before method: " + number.value);
           example.incrementValue(number);
           System.out.println("After method: " + number.value); // Change persists
       }
   }
   ```

4. **Change Object Field**
   ```java
   class Person {
       String name;
   }

   public class ChangeObjectFieldExample {
       public void changeName(Person person) {
           person.name = "John";
       }

       public static void main(String[] args) {
           Person person = new Person();
           person.name = "Alice";
           ChangeObjectFieldExample example = new ChangeObjectFieldExample();
           System.out.println("Before method: " + person.name);
           example.changeName(person);
           System.out.println("After method: " + person.name); // Change persists
       }
   }
   ```

---

### **3. Object Reassignment in Methods**

5. **Object Reassignment**
   ```java
   class Person {
       String name;
   }

   public class ObjectReassignmentExample {
       public void reassignObject(Person person) {
           person = new Person();
           person.name = "New Person";
       }

       public static void main(String[] args) {
           Person person = new Person();
           person.name = "Original Person";
           ObjectReassignmentExample example = new ObjectReassignmentExample();
           System.out.println("Before method: " + person.name);
           example.reassignObject(person);
           System.out.println("After method: " + person.name); // Original object remains unchanged
       }
   }
   ```

6. **Car Reassignment**
   ```java
   class Car {
       String model;
   }

   public class CarReassignmentExample {
       public void modifyCar(Car car) {
           car = new Car();
           car.model = "New Model";
       }

       public static void main(String[] args) {
           Car car = new Car();
           car.model = "Original Model";
           CarReassignmentExample example = new CarReassignmentExample();
           System.out.println("Before method: " + car.model);
           example.modifyCar(car);
           System.out.println("After method: " + car.model); // Original object remains unchanged
       }
   }
   ```

### **4. Combination of Primitives and Objects**

7. **Scaling Object Fields**
   ```java
   class Rectangle {
       int length, breadth;
   }

   public class ScaleObjectExample {
       public void scale(Rectangle rect, int factor) {
           rect.length *= factor;
           rect.breadth *= factor;
       }

       public static void main(String[] args) {
           Rectangle rect = new Rectangle();
           rect.length = 5;
           rect.breadth = 3;
           ScaleObjectExample example = new ScaleObjectExample();
           System.out.println("Before method: " + rect.length + ", " + rect.breadth);
           example.scale(rect, 2);
           System.out.println("After method: " + rect.length + ", " + rect.breadth); // Change persists
       }
   }
   ```

8. **Updating Object Fields**
   ```java
   class Account {
       double balance;
       String accountHolder;
   }

   public class UpdateAccountExample {
       public void updateAccount(Account account, double newBalance, String newHolder) {
           account.balance = newBalance;
           account.accountHolder = newHolder;
       }

       public static void main(String[] args) {
           Account account = new Account();
           account.balance = 1000.0;
           account.accountHolder = "Alice";
           UpdateAccountExample example = new UpdateAccountExample();
           System.out.println("Before method: " + account.balance + ", " + account.accountHolder);
           example.updateAccount(account, 2000.0, "Bob");
           System.out.println("After method: " + account.balance + ", " + account.accountHolder); // Change persists
       }
   }
   ```

### **5. Complex Behavior with Pass by Value**

9. **Swapping Coordinates**
   ```java
   class Point {
       int x, y;
   }

   public class SwapCoordinatesExample {
       public void swapCoordinates(Point point) {
           int temp = point.x;
           point.x = point.y;
           point.y = temp;
       }

       public static void main(String[] args) {
           Point point = new Point();
           point.x = 5;
           point.y = 10;
           SwapCoordinatesExample example = new SwapCoordinatesExample();
           System.out.println("Before method: x = " + point.x + ", y = " + point.y);
           example.swapCoordinates(point);
           System.out.println("After method: x = " + point.x + ", y = " + point.y); // Change persists
       }
   }
   ```

10. **Giving Bonus**
    ```java
    class Employee {
        double salary;
    }

    public class BonusExample {
        public void giveBonus(Employee emp, double bonus) {
            emp.salary += bonus;
        }

        public static void main(String[] args) {
            Employee emp = new Employee();
            emp.salary = 50000.0;
            BonusExample example = new BonusExample();
            System.out.println("Before method: " + emp.salary);
            example.giveBonus(emp, 5000.0);
            System.out.println("After method: " + emp.salary); // Change persists
        }
    }
    ```

### **6. Pass by Value and Immutability**

13. **String Append**
    ```java
    public class StringAppendExample {
        public void appendText(String str) {
            str += " World";
            System.out.println("Inside method: " + str);
        }

        public static void main(String[] args) {
            String text = "Hello";
            StringAppendExample example = new StringAppendExample();
            System.out.println("Before method: " + text);
            example.appendText(text);
            System.out.println("After method: " + text); // Original string remains unchanged
        }
    }
    ```

14. **Immutable Field**
    ```java
    class BankAccount {
        final String accountNumber;
        double balance;

        public BankAccount(String accountNumber, double balance) {
            this.accountNumber = accountNumber;
            this.balance = balance;
        }
    }

    public class ImmutableExample {
        public void updateAccountDetails(BankAccount account, double newBalance) {
            account.balance = newBalance;
            // account.accountNumber = "NewNumber"; // Error: Cannot reassign final field
        }

        public static void main(String[] args) {
            BankAccount account = new BankAccount("123456", 1000.0);
            ImmutableExample example = new ImmutableExample();
            System.out.println("Before method: " + account.balance);
            example.updateAccountDetails(account, 2000.0);
            System.out.println("After method: " + account.balance); // Change to balance persists
        }
    }
    ```
