### **1. Local Variables**
**Snippet:**
```java
public class LocalVariableDemo {
    public void showLocalVariable() {
        int localVar = 10; // Local variable
        System.out.println("Local variable: " + localVar);
    }

    public static void main(String[] args) {
        LocalVariableDemo demo = new LocalVariableDemo();
        demo.showLocalVariable(); // Output: Local variable: 10
    }
}
```

**Exercises:**
1. Write a method that calculates the sum of two local variables and returns the result.
2. Create a program where you declare and initialize a local variable in one method, and try to access it in another method. Observe and fix the error.

### **5. Exercises**

#### **Exercise 1: Local Variable Scope**
Write a method that calculates the area of a rectangle using two local variables `length` and `breadth`.

#### **Solution:**
```java
public class RectangleArea {
    public void calculateArea() {
        int length = 5; // Local variable
        int breadth = 10; // Local variable
        int area = length * breadth; // Local computation
        System.out.println("Area of rectangle: " + area);
    }

    public static void main(String[] args) {
        RectangleArea rectangle = new RectangleArea();
        rectangle.calculateArea(); // Output: Area of rectangle: 50
    }
}
```

#### **Exercise 2: Instance Variable Behavior**
Create a class `Student` with instance variables `name` and `marks`. Write methods to set and display these values.

#### **Solution:**
```java
public class Student {
    String name; // Instance variable
    int marks;   // Instance variable

    public void setDetails(String name, int marks) {
        this.name = name;
        this.marks = marks;
    }

    public void displayDetails() {
        System.out.println("Name: " + name + ", Marks: " + marks);
    }

    public static void main(String[] args) {
        Student student1 = new Student();
        student1.setDetails("Alice", 85);
        student1.displayDetails(); // Output: Name: Alice, Marks: 85

        Student student2 = new Student();
        student2.setDetails("Bob", 90);
        student2.displayDetails(); // Output: Name: Bob, Marks: 90
    }
}
```

Create a class `Car` with a static variable `count` to track how many cars are created.

#### **Solution:**

#### **Exercise 4: Combined Example**
Create a class `BankAccount` with:
- A static variable `bankName`.
- Instance variables `accountNumber` and `balance`.
- A method to display account details.

#### **Solution:**
```java
public class BankAccount {
    static String bankName = "Global Bank"; // Static variable
    String accountNumber; // Instance variable
    double balance;       // Instance variable

    public BankAccount(String accountNumber, double balance) {
        this.accountNumber = accountNumber;
        this.balance = balance;
    }

    public void displayAccountDetails() {
        System.out.println("Bank: " + bankName);
        System.out.println("Account Number: " + accountNumber);
        System.out.println("Balance: $" + balance);
    }

    public static void main(String[] args) {
        BankAccount account1 = new BankAccount("12345", 1000.0);
        BankAccount account2 = new BankAccount("67890", 5000.0);

        account1.displayAccountDetails();
        account2.displayAccountDetails();
    }
}
```
