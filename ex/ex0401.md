### **1. Basic Function Implementation**

1. **Greet Function**
   ```python
   def greet(name):
       print(f"Hello, {name}!")

   greet("Alice")
   ```

2. **Multiply Function**
   ```python
   def multiply(a, b):
       return a * b

   print(multiply(3, 5))
   ```

### **2. Functions with Conditional Logic**

3. **Positive Number Check**
   ```python
   def is_positive(number):
       return number > 0

   print(is_positive(-5))  # Output: False
   ```

4. **Maximum of Two Numbers**
   ```python
   def max_of_two(a, b):
       return a if a > b else b

   print(max_of_two(7, 3))  # Output: 7
   ```

---

### **3. Using Loops in Functions**

5. **Sum of Numbers Up To n**
   ```python
   def sum_upto(n):
       total = 0
       for i in range(1, n + 1):
           total += i
       return total

   print(sum_upto(5))  # Output: 15
   ```

6. **Factorial**
   ```python
   def factorial(n):
       result = 1
       for i in range(1, n + 1):
           result *= i
       return result

   print(factorial(4))  # Output: 24
   ```

---

### **4. Recursive Functions**

7. **Power Function**
   ```python
   def power(base, exponent):
       if exponent == 0:
           return 1
       return base * power(base, exponent - 1)

   print(power(2, 3))  # Output: 8
   ```

8. **Sum of Digits**
   ```python
   def sum_digits(n):
       if n == 0:
           return 0
       return n % 10 + sum_digits(n // 10)

   print(sum_digits(123))  # Output: 6
   ```

---

### **5. Functions with Simple Mathematical Logic**

9. **Reverse a Number**
   ```python
   def reverse_number(n):
       reversed_num = 0
       while n > 0:
           reversed_num = reversed_num * 10 + n % 10
           n //= 10
       return reversed_num

   print(reverse_number(1234))  # Output: 4321
   ```

10. **Prime Number Check**
    ```python
    def is_prime(n):
        if n < 2:
            return False
        for i in range(2, int(n**0.5) + 1):
            if n % i == 0:
                return False
        return True

    print(is_prime(7))  # Output: True
    ```

---

### **6. Functions with Iterative Logic**

11. **Count Digits**
    ```python
    def count_digits(n):
        count = 0
        while n > 0:
            count += 1
            n //= 10
        return count

    print(count_digits(12345))  # Output: 5
    ```

12. **Print Pyramid**
    ```python
    def print_pyramid(n):
        for i in range(1, n + 1):
            print(" " * (n - i) + "*" * (2 * i - 1))

    print_pyramid(3)
    ```

---

### **7. Number Series and Patterns**

13. **Nth Fibonacci Number**
    ```python
    def fibonacci_nth(n):
        a, b = 0, 1
        for _ in range(1, n):
            a, b = b, a + b
        return b

    print(fibonacci_nth(6))  # Output: 8
    ```

14. **Sum of Multiples**
    ```python
    def sum_of_multiples(x, n):
        total = 0
        for i in range(1, n + 1):
            total += x * i
        return total

    print(sum_of_multiples(3, 4))  # Output: 30
    ```

---

### **8. Advanced Function Logic**

15. **Greatest Common Divisor (GCD)**
    ```python
    def gcd(a, b):
        while b != 0:
            a, b = b, a % b
        return a

    print(gcd(48, 18))  # Output: 6
    ```

16. **Least Common Multiple (LCM)**
    ```python
    def lcm(a, b):
        return a * b // gcd(a, b)

    print(lcm(4, 6))  # Output: 12
    ```
