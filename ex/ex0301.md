
# **Basic Decision-Making Questions**
1. **Simple If Statement**
   - Write a Java program that checks if a given number is positive. If it is, print "The number is positive."

2. **If-Else Statement**
   - Write a program to determine whether a person is eligible to vote based on their age. If the person is 18 or older, print "Eligible to vote"; otherwise, print "Not eligible to vote."

3. **Nested If Statement**
   - Write a program that takes three numbers as input and prints the largest of the three using nested `if` statements.

4. **Switch Statement**
   - Write a Java program that takes a day of the week (1 for Monday, 2 for Tuesday, etc.) as input and prints the corresponding day name. Use a `switch` statement.

5. **Ternary Operator**
   - Write a program that takes a number as input and uses the ternary operator to determine if the number is even or odd.

---

### **Intermediate Decision-Making Questions**
6. **Multiple Conditions**
   - Write a program to determine whether a given year is a leap year. A year is a leap year if it is divisible by 4, but not divisible by 100, unless it is also divisible by 400.

7. **Grade Assignment**
   - Write a program that accepts a student's score (0-100) as input and assigns a grade:
     - `A` for scores 90 and above
     - `B` for scores 80-89
     - `C` for scores 70-79
     - `D` for scores 60-69
     - `F` for scores below 60

8. **Menu-Driven Program**
   - Write a menu-driven Java program where the user can select an operation (+, -, *, /) to perform on two numbers. Use a `switch` statement to implement the decision-making.

---

### **Advanced Decision-Making Questions**
9. **Nested Decision-Making with Logical Operators**
   - Write a program that takes the temperature as input and decides the following:
     - If the temperature is below 0, print "Freezing weather."
     - If it is between 0 and 15, print "Cold weather."
     - If it is between 16 and 25, print "Moderate weather."
     - If it is above 25, print "Hot weather."

10. **Complex Condition Checking**
    - Write a program to determine whether a triangle is valid based on its angles. A triangle is valid if the sum of its three angles is equal to 180 degrees, and each angle is greater than 0. Print "Valid triangle" or "Invalid triangle" accordingly.

---

```java
public class LargestOfThree {
    public static void main(String[] args) {
        int a = 10, b = 20, c = 15;
        if (a > b) {
            if (a > c) {
                System.out.println("Largest number is: " + a);
            } else {
                System.out.println("Largest number is: " + c);
            }
        } else {
            if (b > c) {
                System.out.println("Largest number is: " + b);
            } else {
                System.out.println("Largest number is: " + c);
            }
        }
    }
}
```

public class DayOfWeek {

            case 2: System.out.println("Tuesday"); break;

### **8. Menu-Driven Program**
```java
import java.util.Scanner;

public class Calculator {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter two numbers:");
        double num1 = sc.nextDouble();
        double num2 = sc.nextDouble();

        System.out.println("Choose operation: +, -, *, /");
        char operator = sc.next().charAt(0);

        switch (operator) {
            case '+': System.out.println("Result: " + (num1 + num2)); break;
            case '-': System.out.println("Result: " + (num1 - num2)); break;
            case '*': System.out.println("Result: " + (num1 * num2)); break;
            case '/': 
                if (num2 != 0) {
                    System.out.println("Result: " + (num1 / num2));
                } else {
                    System.out.println("Division by zero is not allowed.");
                }
                break;
            default: System.out.println("Invalid operator");
        }
    }
}
```
