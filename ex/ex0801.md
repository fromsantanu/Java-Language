# Here are exercises on Types of Exceptions (Checked vs Unchecked)

---

### **Exercises: Checked Exceptions**

#### **Exercise 1: File Reading**
1. Write a program that reads a file named `example.txt`.
2. Handle the checked exception `FileNotFoundException` using a `try-catch` block.

---

#### **Exercise 2: Handle InterruptedException**
1. Write a program that pauses execution for 2 seconds using `Thread.sleep(2000)`.
2. Handle the `InterruptedException` using a `try-catch` block.

---

#### **Exercise 3: Handle SQLException**
1. Simulate a database connection and throw a `SQLException` manually using `throw new SQLException("Database connection failed");`.
2. Handle the exception using a `try-catch` block and print an appropriate message.

---

#### **Exercise 4: Checked Exception in Method**
1. Write a method `readFile(String fileName)` that:
   - Reads a file and throws `IOException`.
2. Call this method from `main()` and handle the exception using a `try-catch` block.

---

#### **Exercise 5: Custom Checked Exception**
1. Create a custom checked exception class `InvalidAgeException` that extends `Exception`.
2. Write a method `checkAge(int age)` that:
   - Throws `InvalidAgeException` if the age is less than 18.
3. Call the method from `main()` and handle the exception.

---

### **Exercises: Unchecked Exceptions**

#### **Exercise 6: ArithmeticException**
1. Write a program that attempts to divide a number by zero.
2. Handle the `ArithmeticException` using a `try-catch` block.

---

#### **Exercise 7: ArrayIndexOutOfBoundsException**
1. Write a program that creates an array of size 5 and tries to access the 10th element.
2. Handle the `ArrayIndexOutOfBoundsException` using a `try-catch` block.

---

#### **Exercise 8: NullPointerException**
1. Write a program that initializes a string to `null` and tries to call a method (e.g., `toUpperCase()`) on it.
2. Handle the `NullPointerException` using a `try-catch` block.

---

#### **Exercise 9: NumberFormatException**
1. Write a program that tries to convert a non-numeric string (e.g., `"abc"`) into an integer using `Integer.parseInt()`.
2. Handle the `NumberFormatException` using a `try-catch` block.

---

#### **Exercise 10: Custom Unchecked Exception**
1. Create a custom unchecked exception class `NegativeValueException` that extends `RuntimeException`.
2. Write a method `validateValue(int value)` that:
   - Throws `NegativeValueException` if the value is less than 0.
3. Call the method from `main()` and handle the exception.

---

### **Advanced Exercises**

#### **Exercise 11: Multiple Exceptions**
1. Write a program that:
   - Divides two numbers (handle `ArithmeticException`).
   - Accesses an invalid index of an array (handle `ArrayIndexOutOfBoundsException`).
   - Handles both exceptions using a single `try-catch` block.

---

#### **Exercise 12: Nested Try-Catch**
1. Write a program that:
   - Handles `ArithmeticException` in an inner `try` block.
   - Handles `NullPointerException` in an outer `try` block.

---

#### **Exercise 13: Rethrow Exception**
1. Write a program that:
   - Catches an `IOException` in a method.
   - Rethrows the exception to the caller method.

---

#### **Exercise 14: Finally Block**
1. Write a program that:
   - Divides two numbers and handles `ArithmeticException`.
   - Includes a `finally` block that prints `"Execution Completed"` regardless of the outcome.

---

#### **Exercise 15: Exception Propagation**
1. Write a program with three methods:
   - `method1()` calls `method2()`.
   - `method2()` calls `method3()`.
   - `method3()` throws an unchecked exception.
2. Demonstrate exception propagation across methods and handle it in `method1()`.

---

These exercises cover both **checked exceptions** (e.g., `IOException`, `SQLException`) and **unchecked exceptions** (e.g., `ArithmeticException`, `NullPointerException`), as well as advanced exception handling techniques. Let me know if you’d like solutions for these!

## Here are the solutions for the **"Types of Exceptions (Checked vs Unchecked)"** exercises in Java:

---

### **Solutions: Checked Exceptions**

#### **Solution 1: File Reading**
```java
import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        try {
            File file = new File("example.txt");
            Scanner scanner = new Scanner(file);
            while (scanner.hasNextLine()) {
                System.out.println(scanner.nextLine());
            }
        } catch (FileNotFoundException e) {
            System.out.println("File not found: " + e.getMessage());
        }
    }
}
```

---

#### **Solution 2: Handle InterruptedException**
```java
public class Main {
    public static void main(String[] args) {
        try {
            System.out.println("Pausing execution...");
            Thread.sleep(2000);
            System.out.println("Resumed after 2 seconds.");
        } catch (InterruptedException e) {
            System.out.println("Thread was interrupted: " + e.getMessage());
        }
    }
}
```

---

#### **Solution 3: Handle SQLException**
```java
import java.sql.SQLException;

public class Main {
    public static void main(String[] args) {
        try {
            throw new SQLException("Database connection failed");
        } catch (SQLException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
```

---

#### **Solution 4: Checked Exception in Method**
```java
import java.io.File;
import java.io.IOException;
import java.util.Scanner;

public class Main {
    public static void readFile(String fileName) throws IOException {
        File file = new File(fileName);
        Scanner scanner = new Scanner(file);
        while (scanner.hasNextLine()) {
            System.out.println(scanner.nextLine());
        }
    }

    public static void main(String[] args) {
        try {
            readFile("example.txt");
        } catch (IOException e) {
            System.out.println("Error reading file: " + e.getMessage());
        }
    }
}
```

---

#### **Solution 5: Custom Checked Exception**
```java
class InvalidAgeException extends Exception {
    public InvalidAgeException(String message) {
        super(message);
    }
}

public class Main {
    public static void checkAge(int age) throws InvalidAgeException {
        if (age < 18) {
            throw new InvalidAgeException("Age must be 18 or older.");
        }
        System.out.println("Age is valid.");
    }

    public static void main(String[] args) {
        try {
            checkAge(16);
        } catch (InvalidAgeException e) {
            System.out.println("Exception: " + e.getMessage());
        }
    }
}
```

class NegativeValueException extends RuntimeException {

### **Advanced Solutions**

#### **Solution 11: Multiple Exceptions**

    public static void main(String[] args) {

#### **Solution 12: Nested Try-Catch**
```java
public class Main {
    public static void main(String[] args) {
        try {
            String str = null;
            try {
                int result = 10 / 0;
            } catch (ArithmeticException e) {
                System.out.println("Inner Exception: " + e.getMessage());
            }
            System.out.println(str.toUpperCase());
        } catch (NullPointerException e) {
            System.out.println("Outer Exception: " + e.getMessage());
        }
    }
}
```

---

#### **Solution 13: Rethrow Exception**
```java
import java.io.IOException;

public class Main {
    public static void readFile() throws IOException {
        throw new IOException("File not found.");
    }

    public static void main(String[] args) {
        try {
            readFile();
        } catch (IOException e) {
            System.out.println("Caught Exception: " + e.getMessage());
        }
    }
}
```

---

#### **Solution 14: Finally Block**
```java
public class Main {
    public static void main(String[] args) {
        try {
            int result = 10 / 0;
        } catch (ArithmeticException e) {
            System.out.println("Exception: " + e.getMessage());
        } finally {
            System.out.println("Execution Completed");
        }
    }
}
```

---

#### **Solution 15: Exception Propagation**
```java
public class Main {
    public static void method3() {
        throw new ArithmeticException("Exception in method3");
    }

    public static void method2() {
        method3();
    }

    public static void method1() {
        try {
            method2();
        } catch (ArithmeticException e) {
            System.out.println("Caught Exception: " + e.getMessage());
        }
    }

    public static void main(String[] args) {
        method1();
    }
}
```
