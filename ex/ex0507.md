# Here are focused exercises on **Encapsulation and Access Modifiers** in Java:

---

### **Exercise 1: Basic Encapsulation**
1. Create a class `Person` with:
   - Private fields `String name` and `int age`.
   - Public getter and setter methods for both fields.

2. In the `main()` method:
   - Create a `Person` object.
   - Set the values of `name` and `age` using the setter methods.
   - Retrieve and print the values using the getter methods.

---

### **Exercise 2: Validating Input in Setters**
1. Modify the `Person` class from Exercise 1:
   - Add validation to the `setAge()` method to ensure that age is non-negative.
   - If the input is invalid, print an error message and do not update the field.

2. In the `main()` method:
   - Test the validation by attempting to set a negative age.

---

### **Exercise 3: Read-Only Property**
1. Create a class `Product` with:
   - A private field `String productId`.
   - A public constructor to initialize `productId`.
   - A getter method for `productId`.
   - No setter method for `productId` to make it read-only.

2. In the `main()` method:
   - Create a `Product` object and initialize the `productId`.
   - Attempt to retrieve and modify the `productId` to observe the behavior.

---

### **Exercise 4: Write-Only Property**
1. Create a class `Employee` with:
   - A private field `double salary`.
   - A setter method for `salary` but no getter method to make it write-only.

2. In the `main()` method:
   - Create an `Employee` object and set its `salary`.
   - Attempt to retrieve the `salary` to observe the behavior.

---

### **Exercise 5: Access Modifiers in the Same Class**
1. Create a class `TestModifiers` with:
   - A private field `int privateVar`.
   - A default (package-private) field `int defaultVar`.
   - A protected field `int protectedVar`.
   - A public field `int publicVar`.
   - Methods to print the values of all fields.

2. In the `main()` method (within the same class):
   - Access and modify all fields directly and print their values.

---

### **Exercise 6: Access Modifiers in a Different Class**
1. Create a class `TestModifiers` with fields as in Exercise 5.

2. Create another class `ModifierTester` in the same package:
   - Attempt to access each field of `TestModifiers` from this class and print their values.
   - Observe which fields are accessible.

---

### **Exercise 7: Access Modifiers in a Subclass**
1. Create a class `Parent` with:
   - A private field `int privateField`.
   - A default field `int defaultField`.
   - A protected field `int protectedField`.
   - A public field `int publicField`.

2. Create a subclass `Child` that extends `Parent`:
   - Attempt to access each field in the subclass.
   - Observe which fields are accessible.

---

### **Exercise 8: Private Method Encapsulation**
1. Create a class `Account` with:
   - A private method `calculateInterest()` that returns the interest based on some logic.
   - A public method `getInterest()` that calls `calculateInterest()` and returns its value.

2. In the `main()` method:
   - Create an `Account` object and call `getInterest()`.
   - Attempt to call `calculateInterest()` directly to observe the behavior.

---

### **Exercise 9: Encapsulation with Constructor**
1. Create a class `Book` with:
   - Private fields `String title` and `String author`.
   - A constructor to initialize both fields.

2. In the `main()` method:

### **Exercise 10: Access Modifiers with Packages**
1. Create a package `package1` containing a class `ClassA` with:
   - A private field.
   - A default field.
   - A protected field.
   - A public field.

2. Create another package `package2` containing a class `ClassB`:
   - Extend `ClassA`.
   - Attempt to access all fields of `ClassA` in `ClassB`.

## Here are the solutions to the exercises on **Encapsulation and Access Modifiers** in Java:

---

### **Solution 1: Basic Encapsulation**
```java
class Person {
    private String name;
    private int age;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        this.age = age;
    }
}

public class Main {
    public static void main(String[] args) {
        Person person = new Person();
        person.setName("Alice");
        person.setAge(25);

        System.out.println("Name: " + person.getName());
        System.out.println("Age: " + person.getAge());
    }
}
```

### **Solution 2: Validating Input in Setters**
```java
class Person {
    private String name;
    private int age;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        if (age >= 0) {
            this.age = age;
        } else {
            System.out.println("Age cannot be negative.");
        }
    }
}

public class Main {
    public static void main(String[] args) {
        Person person = new Person();
        person.setName("Bob");
        person.setAge(-5); // Invalid input
        person.setAge(30); // Valid input

        System.out.println("Name: " + person.getName());
        System.out.println("Age: " + person.getAge());
    }
}
```

### **Solution 5: Access Modifiers in the Same Class**
```java
class TestModifiers {

    void displayFields() {
        System.out.println("Private: " + privateVar);

        System.out.println("Public: " + publicVar);

        TestModifiers obj = new TestModifiers();

    }
```

### **Solution 10: Access Modifiers with Packages**
**`package1/ClassA.java`**
```java
package package1;

public class ClassA {
    private int privateField = 10;
    int defaultField = 20;
    protected int protectedField = 30;
    public int publicField = 40;
}
```

**`package2/ClassB.java`**
```java
package package2;

import package1.ClassA;

public class ClassB extends ClassA {
    void accessFields() {
        // System.out.println("Private: " + privateField); // Not accessible
        // System.out.println("Default: " + defaultField); // Not accessible
        System.out.println("Protected: " + protectedField); // Accessible in subclass
        System.out.println("Public: " + publicField); // Accessible everywhere
    }

    public static void main(String[] args) {
        ClassB obj = new ClassB();
        obj.accessFields();
    }
}
```
