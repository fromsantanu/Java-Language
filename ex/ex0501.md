# Here are focused exercises on constructing **Classes and Objects** in Java:

---

### **Exercise 1: Basic Class Definition**
1. Create a class named `Person` with the following attributes:
   - `String name`
   - `int age`

2. In the `main()` method:
   - Create an object of the `Person` class.
   - Assign values to the attributes using the dot operator.
   - Print the values of the attributes.

---

### **Exercise 2: Adding Methods**
1. Create a class named `Book` with the following attributes:
   - `String title`
   - `String author`

2. Add a method `displayBookInfo()` that prints the title and author of the book.

3. In the `main()` method:
   - Create an object of the `Book` class.
   - Assign values to the attributes.
   - Call `displayBookInfo()`.

---

### **Exercise 3: Multiple Objects**
1. Create a class named `Dog` with the following attributes:
   - `String breed`
   - `String color`

2. In the `main()` method:
   - Create three objects of the `Dog` class.
   - Assign different values to each object’s attributes.
   - Print the details of all three dogs.

---

### **Exercise 4: Object Interaction**
1. Create a class named `Student` with the following attributes:
   - `String name`
   - `int marks`

2. Add a method `compareMarks(Student anotherStudent)`:
   - This method compares the marks of the current student object with another student and prints which student has higher marks.

3. In the `main()` method:
   - Create two `Student` objects.
   - Assign values to their attributes.
   - Call `compareMarks()` to compare their marks.

---

### **Exercise 5: Working with Arrays of Objects**
1. Create a class named `Product` with the following attributes:
   - `String name`
   - `double price`

2. In the `main()` method:
   - Create an array of `Product` objects to store details of three products.
   - Assign values to each product object.
   - Print the details of all the products using a loop.

---

### **Exercise 6: Default Values**
1. Create a class named `Employee` with the following attributes:
   - `String name`
   - `double salary`

2. In the `main()` method:

### **Exercise 7: Methods with Parameters**
1. Create a class named `Rectangle` with the following attributes:

### **Exercise 8: Objects as Parameters**
1. Create a class named `Point` with the following attributes:

2. Add a method `distanceFrom(Point otherPoint)`:
   - This method calculates and returns the distance between the current point and `otherPoint`.

3. In the `main()` method:
   - Create two `Point` objects with different coordinates.
   - Call `distanceFrom()` to calculate the distance between them and print the result.

---

### **Exercise 9: Object Reference**
1. Create a class named `Account` with the following attributes:
   - `String accountHolder`
   - `double balance`

2. In the `main()` method:
   - Create an object of the `Account` class.
   - Create another object that references the first object.
   - Modify the balance using one reference and observe the changes using the other reference.

### **Exercise 10: Passing Primitive vs. Object**
1. Create a class named `Calculator` with a method `increment(int num)`:
   - The method increases the value of `num` by 1 and prints it.

2. Add another method `incrementBalance(Account account)`:
   - This method increases the `balance` of the `Account` object by 1 and prints it.

3. In the `main()` method:
   - Call `increment()` with a primitive value and observe the result.
   - Call `incrementBalance()` with an `Account` object and observe the result.

2. In the `main()` method:
   - Create an object of the `Library` class.
   - Create a `Book` object using the `Library` object.
   - Assign values to all attributes and print them.

class Person {

### **Solution 4: Object Interaction**
```java
class Student {
    String name;
    int marks;

    void compareMarks(Student anotherStudent) {
        if (this.marks > anotherStudent.marks) {
            System.out.println(this.name + " has higher marks.");
        } else if (this.marks < anotherStudent.marks) {
            System.out.println(anotherStudent.name + " has higher marks.");
        } else {
            System.out.println("Both have equal marks.");
        }
    }
}

public class Main {
    public static void main(String[] args) {
        Student student1 = new Student();
        student1.name = "John";
        student1.marks = 85;

        Student student2 = new Student();
        student2.name = "Jane";
        student2.marks = 90;

        student1.compareMarks(student2);
    }
}
```

### **Solution 8: Objects as Parameters**
```java
class Point {
    int x;
    int y;

    double distanceFrom(Point otherPoint) {
        return Math.sqrt(Math.pow(this.x - otherPoint.x, 2) + Math.pow(this.y - otherPoint.y, 2));
    }
}

public class Main {
    public static void main(String[] args) {
        Point p1 = new Point();
        p1.x = 3;
        p1.y = 4;

        Point p2 = new Point();
        p2.x = 0;
        p2.y = 0;

        System.out.println("Distance: " + p1.distanceFrom(p2));
    }
}
```

### **Solution 10: Passing Primitive vs. Object**
```java
class Calculator {
    void increment(int num) {
        num++;
        System.out.println("Incremented Primitive Value: " + num);
    }

    void incrementBalance(Account account) {
        account.balance++;
        System.out.println("Incremented Account Balance: " + account.balance);
    }
}

class Account {
    double balance;
}

public class Main {
    public static void main(String[] args) {
        Calculator calculator = new Calculator();

        int number = 10;
        calculator.increment(number);
        System.out.println("Original Number: " + number);

        Account account = new Account();
        account.balance = 1000.0;
        calculator.incrementBalance(account);
        System.out.println("Original Account Balance: " + account.balance);
    }
}
```

### **Solution 11: Nested Classes**
```java
class Library {
    String libraryName;

    class Book {
        String bookTitle;
        String author;

        void displayBookInfo() {
            System.out.println("Library: " + libraryName);
            System.out.println("Book Title: " + bookTitle);
            System.out.println("Author: " + author);
        }
    }
}

public class Main {
    public static void main(String[] args) {
        Library library = new Library();
        library.libraryName = "Central Library";

        Library.Book book = library.new Book();
        book.bookTitle = "1984";
        book.author = "George Orwell";

        book.displayBookInfo();
    }
}
```
