# Exercises on Method Overloading
### **1. Basic Method Overloading**
1. **Exercise**: Create a class `Calculator` with an overloaded method `add`.  
   - One version should take two integers and return their sum.  
   - Another version should take three integers and return their sum.

2. **Exercise**: Create a class `Greeting` with an overloaded method `sayHello`.  
   - One version should take no arguments and print `"Hello!"`.  
   - Another version should take a `String` (name) as an argument and print `"Hello, [name]!"`.

---

### **2. Method Overloading with Different Parameter Types**
3. **Exercise**: Create a class `Multiplier` with an overloaded method `multiply`.  
   - One version should take two integers and return their product.  
   - Another version should take two `double` values and return their product.

4. **Exercise**: Write a class `Printer` with an overloaded method `printMessage`.  
   - One version should take a `String` and print it.  
   - Another version should take a `String` and an `int`, and print the `String` repeated `n` times.

---

### **3. Method Overloading with Different Numbers of Arguments**
5. **Exercise**: Create a class `Rectangle` with an overloaded method `area`.  
   - One version should take one argument and calculate the area of a square (side × side).  
   - Another version should take two arguments and calculate the area of a rectangle (length × breadth).

6. **Exercise**: Create a class `PowerCalculator` with an overloaded method `power`.  
   - One version should take one argument and return the square of the number.  
   - Another version should take two arguments and return the first number raised to the power of the second.

---

### **4. Method Overloading with Variable Parameter Types**
7. **Exercise**: Create a class `DistanceConverter` with an overloaded method `convertToMeters`.  
   - One version should take an `int` representing centimeters and return the equivalent in meters as a `double`.  
   - Another version should take a `double` representing kilometers and return the equivalent in meters as a `double`.

8. **Exercise**: Write a class `Concatenator` with an overloaded method `concatenate`.  
   - One version should take two `String` arguments and return their concatenation.  
   - Another version should take three `String` arguments and return their concatenation.

---

### **5. Method Overloading with Logical Variations**
9. **Exercise**: Create a class `InterestCalculator` with an overloaded method `calculateInterest`.  
   - One version should take a `double` principal and `double` rate and return the simple interest for 1 year.  
   - Another version should take a `double` principal, `double` rate, and `int` time (in years) and return the total interest.

10. **Exercise**: Write a class `Shape` with an overloaded method `perimeter`.  
    - One version should calculate the perimeter of a square (takes one side as input).  
    - Another version should calculate the perimeter of a rectangle (takes length and breadth as input).

---

### **6. Real-World Scenarios**
11. **Exercise**: Create a class `PaymentProcessor` with an overloaded method `processPayment`.  
    - One version should take a `String` cardNumber and a `double` amount to process a credit card payment.  
    - Another version should take a `String` email and a `double` amount to process a PayPal payment.

12. **Exercise**: Write a class `DataSaver` with an overloaded method `save`.  
    - One version should take a `String` fileName and `String` data and print a message indicating the data is saved to a file.  
    - Another version should take a `String` databaseName, `String` tableName, and `String` data and print a message indicating the data is saved to the database.

---

### **7. Advanced Method Overloading**
13. **Exercise**: Create a class `Converter` with an overloaded method `convert`.  
    - One version should take an `int` and return its `String` representation.  
    - Another version should take a `double` and return its `String` representation formatted to two decimal places.

14. **Exercise**: Write a class `DateFormatter` with an overloaded method `formatDate`.  
    - One version should take a `String` in `yyyy-MM-dd` format and return the same date in `dd/MM/yyyy` format.  
    - Another version should take a `String` in `yyyy-MM-dd` format and a `String` separator and return the date in `dd<separator>MM<separator>yyyy` format.

---

### **1. Basic Method Overloading**

1. **Calculator: Overloaded `add` Method**
   ```java
   public class Calculator {
       public int add(int a, int b) {
           return a + b;
       }

       public int add(int a, int b, int c) {
           return a + b + c;
       }

       public static void main(String[] args) {
           Calculator calc = new Calculator();
           System.out.println(calc.add(3, 5)); // Output: 8
           System.out.println(calc.add(3, 5, 7)); // Output: 15
       }
   }
   ```

2. **Greeting: Overloaded `sayHello` Method**
   ```java
   public class Greeting {
       public void sayHello() {
           System.out.println("Hello!");
       }

       public void sayHello(String name) {
           System.out.println("Hello, " + name + "!");
       }

       public static void main(String[] args) {
           Greeting greeting = new Greeting();
           greeting.sayHello(); // Output: Hello!
           greeting.sayHello("Alice"); // Output: Hello, Alice!
       }
   }
   ```

### **2. Method Overloading with Different Parameter Types**

3. **Multiplier: Overloaded `multiply` Method**
   ```java
   public class Multiplier {
       public int multiply(int a, int b) {
           return a * b;
       }

       public double multiply(double a, double b) {
           return a * b;
       }

       public static void main(String[] args) {
           Multiplier multi = new Multiplier();
           System.out.println(multi.multiply(3, 5)); // Output: 15
           System.out.println(multi.multiply(2.5, 4.0)); // Output: 10.0
       }
   }
   ```

4. **Printer: Overloaded `printMessage` Method**
   ```java
   public class Printer {
       public void printMessage(String message) {
           System.out.println(message);
       }

       public void printMessage(String message, int times) {
           for (int i = 0; i < times; i++) {
               System.out.println(message);
           }
       }

       public static void main(String[] args) {
           Printer printer = new Printer();
           printer.printMessage("Hello!"); // Output: Hello!
           printer.printMessage("Hi!", 3); // Output: Hi! (3 times)
       }
   }
   ```

### **3. Method Overloading with Different Numbers of Arguments**

5. **Rectangle: Overloaded `area` Method**
   ```java
   public class Rectangle {
       public int area(int side) {
           return side * side;
       }

       public int area(int length, int breadth) {
           return length * breadth;
       }

       public static void main(String[] args) {
           Rectangle rect = new Rectangle();
           System.out.println(rect.area(5)); // Output: 25
           System.out.println(rect.area(4, 6)); // Output: 24
       }
   }
   ```

6. **PowerCalculator: Overloaded `power` Method**
   ```java
   public class PowerCalculator {
       public int power(int number) {
           return number * number;
       }

       public int power(int base, int exponent) {
           int result = 1;
           for (int i = 0; i < exponent; i++) {
               result *= base;
           }
           return result;
       }

       public static void main(String[] args) {
           PowerCalculator pc = new PowerCalculator();
           System.out.println(pc.power(4)); // Output: 16
           System.out.println(pc.power(2, 3)); // Output: 8
       }
   }
   ```

### **4. Method Overloading with Variable Parameter Types**

7. **DistanceConverter: Overloaded `convertToMeters` Method**
   ```java
   public class DistanceConverter {
       public double convertToMeters(int centimeters) {
           return centimeters / 100.0;
       }

       public double convertToMeters(double kilometers) {
           return kilometers * 1000;
       }

       public static void main(String[] args) {
           DistanceConverter dc = new DistanceConverter();
           System.out.println(dc.convertToMeters(150)); // Output: 1.5
           System.out.println(dc.convertToMeters(1.2)); // Output: 1200.0
       }
   }
   ```

8. **Concatenator: Overloaded `concatenate` Method**
   ```java
   public class Concatenator {
       public String concatenate(String str1, String str2) {
           return str1 + str2;
       }

       public String concatenate(String str1, String str2, String str3) {
           return str1 + str2 + str3;
       }

       public static void main(String[] args) {
           Concatenator concat = new Concatenator();
           System.out.println(concat.concatenate("Hello, ", "World!")); // Output: Hello, World!
           System.out.println(concat.concatenate("Java ", "is ", "fun!")); // Output: Java is fun!
       }
   }
   ```

### **5. Method Overloading with Logical Variations**

9. **InterestCalculator: Overloaded `calculateInterest` Method**
   ```java
   public class InterestCalculator {
       public double calculateInterest(double principal, double rate) {
           return principal * rate / 100;
       }

       public double calculateInterest(double principal, double rate, int time) {
           return principal * rate * time / 100;
       }

       public static void main(String[] args) {
           InterestCalculator ic = new InterestCalculator();
           System.out.println(ic.calculateInterest(1000, 5)); // Output: 50.0
           System.out.println(ic.calculateInterest(1000, 5, 2)); // Output: 100.0
       }
   }
   ```

10. **Shape: Overloaded `perimeter` Method**
    ```java
    public class Shape {
        public int perimeter(int side) {
            return 4 * side;
        }

        public int perimeter(int length, int breadth) {
            return 2 * (length + breadth);
        }

        public static void main(String[] args) {
            Shape shape = new Shape();
            System.out.println(shape.perimeter(5)); // Output: 20
            System.out.println(shape.perimeter(4, 6)); // Output: 20
        }
    }
    ```

### **6. Real-World Scenarios**

11. **PaymentProcessor: Overloaded `processPayment` Method**
    ```java
    public class PaymentProcessor {
        public void processPayment(String cardNumber, double amount) {
            System.out.println("Processing credit card payment of $" + amount + " using card: " + cardNumber);
        }

        public void processPayment(String email, double amount) {
            System.out.println("Processing PayPal payment of $" + amount + " using email: " + email);
        }

        public static void main(String[] args) {
            PaymentProcessor pp = new PaymentProcessor();
            pp.processPayment("1234-5678-9876", 150.75);
            pp.processPayment("user@example.com", 200.50);
        }
    }
    ```

12. **DataSaver: Overloaded `save` Method**
    ```java
    public class DataSaver {
        public void save(String fileName, String data) {
            System.out.println("Data saved to file: " + fileName);
        }

        public void save(String databaseName, String tableName, String data) {
            System.out.println("Data saved to database: " + databaseName + ", Table: " + tableName);
        }

        public static void main(String[] args) {
            DataSaver ds = new DataSaver();
            ds.save("data.txt", "Sample data");
            ds.save("MyDatabase", "MyTable", "Sample data");
        }
    }
    ```
