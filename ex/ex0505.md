# Here are focused exercises on using the **`super` keyword** in Java:

---

### **Exercise 1: Access Parent Class Method**
1. Create a class `Animal` with:
   - A method `speak()` that prints: `"Animal makes a sound."`

2. Create a class `Dog` that extends `Animal`:
   - Override the `speak()` method to print: `"Dog barks."`
   - Add another method `parentSpeak()` that uses `super` to call the `speak()` method of `Animal`.

3. In the `main()` method:
   - Create a `Dog` object and call both `speak()` and `parentSpeak()`.

---

### **Exercise 2: Access Parent Class Field**
1. Create a class `Person` with:
   - A field `String name` initialized to `"John Doe"`.

2. Create a class `Employee` that extends `Person`:
   - Add a field `String name` initialized to `"Jane Smith"`.
   - Add a method `displayNames()` that prints the value of `name` in both the parent and child classes using `super`.

3. In the `main()` method:
   - Create an `Employee` object and call `displayNames()`.

---

### **Exercise 3: Invoke Parent Class Constructor**
1. Create a class `Vehicle` with:
   - A constructor that prints: `"Vehicle constructor called."`

   - A constructor that calls the parent constructor using `super` and prints: `"Car constructor called."`

3. In the `main()` method:
   - Create a `Car` object and observe the output.

## Here are the solutions to the exercises on **using the `super` keyword** in Java:

---

### **Solution 1: Access Parent Class Method**
```java
class Animal {
    void speak() {
        System.out.println("Animal makes a sound.");
    }
}

class Dog extends Animal {
    @Override
    void speak() {
        System.out.println("Dog barks.");
    }

    void parentSpeak() {
        super.speak(); // Calling parent class method
    }
}

public class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.speak();
        dog.parentSpeak();
    }
}
```

---

### **Solution 2: Access Parent Class Field**
```java
class Person {
    String name = "John Doe";
}

class Employee extends Person {
    String name = "Jane Smith";

    void displayNames() {
        System.out.println("Parent name: " + super.name); // Accessing parent class field
        System.out.println("Child name: " + this.name);
    }
}

public class Main {
    public static void main(String[] args) {
        Employee emp = new Employee();
        emp.displayNames();
    }
}
```

### **Solution 3: Invoke Parent Class Constructor**
```java
class Vehicle {
    Vehicle() {
        System.out.println("Vehicle constructor called.");
    }
}

class Car extends Vehicle {
    Car() {
        super(); // Invoking parent class constructor
        System.out.println("Car constructor called.");
    }
}

public class Main {
    public static void main(String[] args) {
        Car car = new Car();
    }
}
```

### **Solution 6: Using `super` in Overriding Context**
```java
class Employee {
    void work() {
        System.out.println("Employee is working.");
    }
}

class Manager extends Employee {
    @Override
    void work() {
        System.out.println("Manager is managing.");
    }

    void bothWork() {
        super.work(); // Calls Employee's work method
        this.work(); // Calls Manager's work method
    }
}

public class Main {
    public static void main(String[] args) {
        Manager manager = new Manager();
        manager.bothWork();
    }
}
```

### **Solution 7: Using `super` in Overloaded Methods**
```java
class Animal {
    void eat() {
        System.out.println("Animal eats food.");
    }

    void eat(String food) {
        System.out.println("Animal eats " + food + ".");
    }
}

class Bird extends Animal {
    @Override
    void eat(String food) {
        System.out.println("Bird eats " + food + ".");
    }

    void callParentEat() {
        super.eat(); // Calls parent's no-parameter eat method
        super.eat("seeds"); // Calls parent's parameterized eat method
    }
}

public class Main {
    public static void main(String[] args) {
        Bird bird = new Bird();
        bird.callParentEat();
    }
}
```

### **Solution 10: Accessing Parent Class Methods in Overriding Chain**
```java
class GrandParent {
    void show() {
        System.out.println("GrandParent's show.");
    }
}

class Parent extends GrandParent {
    @Override
    void show() {
        System.out.println("Parent's show.");
    }

    void grandParentShow() {
        super.show(); // Calls GrandParent's show method
    }
}

class Child extends Parent {
    @Override
    void show() {
        System.out.println("Child's show.");
    }

    void callGrandParentShow() {
        grandParentShow(); // Indirectly calls GrandParent's show method
    }
}

public class Main {
    public static void main(String[] args) {
        Child child = new Child();
        child.show();
        child.callGrandParentShow();
    }
}
```
