# Here are exercises on try-catch blocks

---

### **Exercise 1: Basic Arithmetic Exception**
1. Write a program that attempts to divide two numbers.
2. If the second number is zero, handle the `ArithmeticException` using a `try-catch` block and display an appropriate message.

---

### **Exercise 2: Array Index Out of Bounds**
1. Create an array of size 5 and try to access the 10th element.
2. Use a `try-catch` block to handle the `ArrayIndexOutOfBoundsException` and display the error message.

---

### **Exercise 3: File Reading Exception**
1. Write a program that reads a file named `nonexistent.txt`.
2. Handle the `FileNotFoundException` using a `try-catch` block and print a message like `"File not found"`.

---

### **Exercise 4: Null Pointer Exception**
1. Write a program that initializes a string to `null`.
2. Attempt to call a method (e.g., `toUpperCase()`) on the null string.
3. Use a `try-catch` block to handle the `NullPointerException` and display an appropriate message.

---

### **Exercise 5: Multiple Exceptions in a Single Try-Catch**
1. Write a program that:
   - Divides two numbers (may cause `ArithmeticException`).
   - Accesses an invalid array index (may cause `ArrayIndexOutOfBoundsException`).
2. Handle both exceptions in a single `try-catch` block and display specific messages for each.

---

### **Exercise 6: Input Mismatch Exception**
1. Write a program that asks the user to input an integer.
2. If the user inputs a non-integer value, handle the `InputMismatchException` using a `try-catch` block and display an error message.

---

### **Exercise 7: String Parsing Exception**
1. Write a program that attempts to convert a non-numeric string (e.g., `"abc"`) into an integer using `Integer.parseInt()`.
2. Use a `try-catch` block to handle the `NumberFormatException` and display an appropriate message.

---

### **Exercise 8: Nested Try-Catch**
1. Write a program that:
   - Handles an `ArithmeticException` in an inner `try-catch`.
   - Handles an `ArrayIndexOutOfBoundsException` in an outer `try-catch`.
2. Use nested `try-catch` blocks to demonstrate error handling at different levels.

---

### **Exercise 9: Finally Block**
1. Write a program that:
   - Divides two numbers and handles `ArithmeticException`.
   - Includes a `finally` block that prints `"Execution Completed"` regardless of the outcome.

---

### **Exercise 10: Custom Exception with Try-Catch**
1. Create a custom exception class `InvalidInputException` that extends `Exception`.
2. Write a program that:
   - Throws `InvalidInputException` if the input value is negative.
   - Handles the exception using a `try-catch` block and displays an appropriate error message.

---

These exercises cover various scenarios of exception handling with **try-catch blocks**, including multiple exceptions, nested try-catch, and custom exceptions. Let me know if you need solutions for these!

## Here are the solutions to the **try-catch block exercises**:

---

### **Solution 1: Basic Arithmetic Exception**
```java
public class Main {
    public static void main(String[] args) {
        try {
            int a = 10, b = 0;
            int result = a / b;
        } catch (ArithmeticException e) {
            System.out.println("Error: Division by zero is not allowed.");
        }
    }
}
```

---

### **Solution 2: Array Index Out of Bounds**
```java
public class Main {
    public static void main(String[] args) {
        try {
            int[] arr = {1, 2, 3, 4, 5};
            System.out.println(arr[10]);
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Error: Invalid array index.");
        }
    }
}
```

---

### **Solution 3: File Reading Exception**
```java
import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        try {
            File file = new File("nonexistent.txt");
            Scanner scanner = new Scanner(file);
        } catch (FileNotFoundException e) {
            System.out.println("File not found.");
        }
    }
}
```

---

### **Solution 4: Null Pointer Exception**
```java
public class Main {
    public static void main(String[] args) {
        try {
            String str = null;
            System.out.println(str.toUpperCase());
        } catch (NullPointerException e) {
            System.out.println("Error: Attempted to access a null object.");
        }
    }
}
```

---

### **Solution 5: Multiple Exceptions in a Single Try-Catch**
```java
public class Main {
    public static void main(String[] args) {
        try {
            int a = 10, b = 0;
            int result = a / b;
            int[] arr = {1, 2, 3};
            System.out.println(arr[5]);
        } catch (ArithmeticException | ArrayIndexOutOfBoundsException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
```

---

### **Solution 6: Input Mismatch Exception**
```java
import java.util.Scanner;
import java.util.InputMismatchException;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        try {
            System.out.print("Enter an integer: ");
            int number = scanner.nextInt();
            System.out.println("You entered: " + number);
        } catch (InputMismatchException e) {
            System.out.println("Error: Please enter a valid integer.");
        }
    }
}
```

---

### **Solution 7: String Parsing Exception**
```java
public class Main {
    public static void main(String[] args) {
        try {
            String str = "abc";
            int number = Integer.parseInt(str);
        } catch (NumberFormatException e) {
            System.out.println("Error: Invalid number format.");
        }
    }
}
```

---

### **Solution 8: Nested Try-Catch**
```java
public class Main {
    public static void main(String[] args) {
        try {
            String str = null;
            try {
                int a = 10, b = 0;
                int result = a / b;
            } catch (ArithmeticException e) {
                System.out.println("Inner Catch: Division by zero.");
            }
            System.out.println(str.toUpperCase());
        } catch (NullPointerException e) {
            System.out.println("Outer Catch: Null pointer exception.");
        }
    }
}
```

---

### **Solution 9: Finally Block**
```java
public class Main {
    public static void main(String[] args) {
        try {
            int a = 10, b = 0;
            int result = a / b;
        } catch (ArithmeticException e) {
            System.out.println("Error: Division by zero is not allowed.");
        } finally {
            System.out.println("Execution Completed");
        }
    }
}
```

---

### **Solution 10: Custom Exception with Try-Catch**
```java
class InvalidInputException extends Exception {
    public InvalidInputException(String message) {
        super(message);
    }
}

public class Main {
    public static void validateInput(int value) throws InvalidInputException {
        if (value < 0) {
            throw new InvalidInputException("Input cannot be negative.");
        }
    }

    public static void main(String[] args) {
        try {
            validateInput(-5);
        } catch (InvalidInputException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
```
