# Here are exercises focused on **Multiple Catch Blocks** and **Nested Try-Catch** in Java:

---

### **Exercises: Multiple Catch Blocks**

#### **Exercise 1: Multiple Exceptions Handling**
1. Write a program that:
   - Divides two numbers (may cause `ArithmeticException`).
   - Accesses an invalid array index (may cause `ArrayIndexOutOfBoundsException`).
   - Parses a non-numeric string into an integer (may cause `NumberFormatException`).
2. Use multiple catch blocks to handle these exceptions separately.

---

#### **Exercise 2: Catching Superclass Exceptions**
1. Write a program that handles:
   - `ArithmeticException`.
   - `ArrayIndexOutOfBoundsException`.
2. Add an additional catch block for `Exception` and demonstrate how it can handle exceptions not caught by the specific catch blocks.

---

#### **Exercise 3: Prioritization in Multiple Catch Blocks**
1. Write a program with multiple catch blocks:
   - One for `ArithmeticException`.
   - One for `Exception`.
2. Show how Java prioritizes specific exceptions over the generic `Exception`.

---

#### **Exercise 4: Re-throwing Exceptions**
1. Write a program that:
   - Catches `ArithmeticException` in one catch block and rethrows it.
   - Handles the rethrown exception in another catch block.

---

#### **Exercise 5: Handle Multiple Exceptions Using `multi-catch`**
1. Write a program that:
   - Handles `NumberFormatException` and `ArrayIndexOutOfBoundsException` using a single `catch` block (multi-catch).
2. Print a different message depending on which exception occurs.

---

### **Exercises: Nested Try-Catch**

#### **Exercise 6: Nested Try-Catch for Arithmetic and Array Exceptions**
1. Write a program with:
   - An outer `try-catch` block to handle `ArrayIndexOutOfBoundsException`.
   - An inner `try-catch` block to handle `ArithmeticException`.

---

#### **Exercise 7: Nested Try-Catch for File Operations**
1. Write a program with:
   - An outer `try-catch` block to handle `FileNotFoundException`.
   - An inner `try-catch` block to handle `IOException`.

---

#### **Exercise 8: Nested Try-Catch with Finally**
1. Write a program with:
   - An outer `try-catch-finally` block that handles `ArithmeticException`.
   - An inner `try-catch` block that handles `NullPointerException`.
   - Use the `finally` block to print `"Outer Try Completed"`.

---

#### **Exercise 9: Nested Try-Catch for Method Calls**
1. Write a program with a method `performDivision()` that:
   - Divides two numbers and may throw `ArithmeticException`.
2. Call this method inside an outer `try-catch` block that handles any exception not caught in the inner `try-catch`.

---

#### **Exercise 10: Propagation in Nested Try-Catch**
1. Write a program where:
   - The inner `try` block throws an exception (e.g., `NullPointerException`).
   - The exception propagates to the outer `try-catch` block if not handled inside the inner block.

---

## Here are the solutions for the **Multiple Catch Blocks** and **Nested Try-Catch** exercises in Java:

---

### **Solutions: Multiple Catch Blocks**

#### **Solution 1: Multiple Exceptions Handling**
```java
public class Main {
    public static void main(String[] args) {
        try {
            int a = 10, b = 0;
            int result = a / b; // May cause ArithmeticException

            int[] arr = {1, 2, 3};
            System.out.println(arr[5]); // May cause ArrayIndexOutOfBoundsException

            int num = Integer.parseInt("abc"); // May cause NumberFormatException
        } catch (ArithmeticException e) {
            System.out.println("Error: Division by zero.");
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Error: Invalid array index.");
        } catch (NumberFormatException e) {
            System.out.println("Error: Invalid number format.");
        }
    }
}
```

---

#### **Solution 2: Catching Superclass Exceptions**

```java
public class Main {
```

#### **Solution 3: Prioritization in Multiple Catch Blocks**

```java
public class Main {

        try {

        } catch (ArithmeticException e) {
```

#### **Solution 4: Re-throwing Exceptions**
```java
public class Main {
    public static void main(String[] args) {
        try {
            try {
                int a = 10, b = 0;
                int result = a / b;
            } catch (ArithmeticException e) {
                System.out.println("Caught ArithmeticException, rethrowing...");
                throw e;
            }
        } catch (ArithmeticException e) {
            System.out.println("Rethrown ArithmeticException caught.");
        }
    }
}
```

---

#### **Solution 5: Handle Multiple Exceptions Using `multi-catch`**
```java
public class Main {

            System.out.println("Error: " + e.getMessage());
```

### **Solutions: Nested Try-Catch**

#### **Solution 6: Nested Try-Catch for Arithmetic and Array Exceptions**
```java
public class Main {
    public static void main(String[] args) {
        try {
            int[] arr = {1, 2, 3};
            try {
                int a = 10, b = 0;
                int result = a / b; // May cause ArithmeticException
            } catch (ArithmeticException e) {
                System.out.println("Inner Catch: ArithmeticException.");
            }
            System.out.println(arr[5]); // May cause ArrayIndexOutOfBoundsException
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Outer Catch: ArrayIndexOutOfBoundsException.");
        }
    }
}
```

---

#### **Solution 7: Nested Try-Catch for File Operations**
```java
import java.io.File;
import java.io.FileNotFoundException;
import java.io.IOException;

public class Main {
    public static void main(String[] args) {
        try {
            File file = new File("example.txt");
            try {
                throw new IOException("Simulated IOException.");
            } catch (IOException e) {
                System.out.println("Inner Catch: " + e.getMessage());
            }
            Scanner scanner = new Scanner(file); // May cause FileNotFoundException
        } catch (FileNotFoundException e) {
            System.out.println("Outer Catch: File not found.");
        }
    }
}
```

---

#### **Solution 8: Nested Try-Catch with Finally**
```java
public class Main {
    public static void main(String[] args) {
        try {
            int a = 10, b = 0;
            try {
                String str = null;
                System.out.println(str.toUpperCase()); // May cause NullPointerException
            } catch (NullPointerException e) {
                System.out.println("Inner Catch: NullPointerException.");
            }
            int result = a / b; // May cause ArithmeticException
        } catch (ArithmeticException e) {
            System.out.println("Outer Catch: ArithmeticException.");
        } finally {
            System.out.println("Outer Try Completed.");
        }
    }
}
```

---

#### **Solution 9: Nested Try-Catch for Method Calls**
```java
public class Main {
    public static void performDivision(int a, int b) {
        try {
            int result = a / b;
        } catch (ArithmeticException e) {
            System.out.println("Inner Catch: Division by zero.");
        }
    }

    public static void main(String[] args) {
        try {
            performDivision(10, 0);
        } catch (Exception e) {
            System.out.println("Outer Catch: Exception caught.");
        }
    }
}
```

---

#### **Solution 10: Propagation in Nested Try-Catch**
```java
public class Main {
    public static void main(String[] args) {
        try {
            try {
                String str = null;
                System.out.println(str.toUpperCase()); // Throws NullPointerException
            } catch (ArithmeticException e) {
                System.out.println("Inner Catch: ArithmeticException.");
            }
        } catch (NullPointerException e) {
            System.out.println("Outer Catch: NullPointerException propagated.");
        }
    }
}
```
