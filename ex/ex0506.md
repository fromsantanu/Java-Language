# Here are focused exercises on **Polymorphism** (both compile-time and runtime) in Java:

---

### **Exercise 1: Compile-Time Polymorphism with Method Overloading**
1. Create a class `Calculator` with:
   - A method `add(int a, int b)` that returns the sum of two integers.
   - An overloaded method `add(double a, double b)` that returns the sum of two doubles.

2. In the `main()` method:
   - Create a `Calculator` object.
   - Call both `add()` methods and print the results.

---

### **Exercise 2: Method Overloading with Different Numbers of Parameters**
1. Extend the `Calculator` class from Exercise 1:
   - Add a method `add(int a, int b, int c)` that returns the sum of three integers.

2. In the `main()` method:
   - Call the new `add()` method with three integers and print the result.

---

### **Exercise 3: Method Overloading with Type Promotion**
1. Create a class `Printer` with:
   - A method `print(int value)` that prints the integer.
   - An overloaded method `print(double value)` that prints the double.
   - An overloaded method `print(String value)` that prints the string.

2. In the `main()` method:
   - Call `print()` with an integer, a double, and a string to observe type promotion and overloading behavior.

### **Exercise 4: Runtime Polymorphism with Method Overriding**
1. Create a class `Animal` with:
   - A method `makeSound()` that prints `"Animal makes a sound."`

2. Create subclasses `Dog` and `Cat` that extend `Animal`:
   - Override `makeSound()` in both classes to print `"Dog barks."` and `"Cat meows."`, respectively.

3. In the `main()` method:
   - Create an array of `Animal` type to store objects of `Dog` and `Cat`.
   - Use a loop to call `makeSound()` on each object.

3. In the `main()` method:

## Here are the solutions to the exercises on **Polymorphism (compile-time and runtime)** in Java:

### **Solution 1: Compile-Time Polymorphism with Method Overloading**
```java
class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }
}

public class Main {
    public static void main(String[] args) {
        Calculator calc = new Calculator();
        System.out.println("Sum of integers: " + calc.add(10, 20));
        System.out.println("Sum of doubles: " + calc.add(10.5, 20.5));
    }
}
```

### **Solution 4: Runtime Polymorphism with Method Overriding**
```java
class Animal {
    void makeSound() {
        System.out.println("Animal makes a sound.");
    }
}

class Dog extends Animal {
    @Override
    void makeSound() {
        System.out.println("Dog barks.");
    }
}

class Cat extends Animal {
    @Override
    void makeSound() {
        System.out.println("Cat meows.");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal[] animals = { new Dog(), new Cat() };

        for (Animal animal : animals) {
            animal.makeSound(); // Runtime polymorphism
        }
    }
}
```

### **Solution 7: Polymorphism with Interfaces**
```java
interface Shape {
    void calculateArea();
}

class Square implements Shape {
    double side;

    Square(double side) {
        this.side = side;
    }

    @Override
    public void calculateArea() {
        System.out.println("Area of square: " + (side * side));
    }
}

class Circle implements Shape {
    double radius;

    Circle(double radius) {
        this.radius = radius;
    }

    @Override
    public void calculateArea() {
        System.out.println("Area of circle: " + (Math.PI * radius * radius));
    }
}

public class Main {
    public static void main(String[] args) {
        Shape square = new Square(5);
        Shape circle = new Circle(3);

        square.calculateArea();
        circle.calculateArea();
    }
}
```

### **Solution 9: Polymorphism with Type Casting**
```java
class Parent {
    void display() {
        System.out.println("Parent display.");
    }
}

class Child extends Parent {
    @Override
    void display() {
        System.out.println("Child display.");
    }
}

public class Main {
    public static void main(String[] args) {
        Parent parentRef = new Child();
        parentRef.display(); // Calls overridden method in Child

        Child child = (Child) parentRef; // Explicit casting
        child.display(); // Calls Child's method directly
    }
}
```

### **Solution 10: Polymorphism in Collections**
```java
import java.util.ArrayList;

class Employee {
    String getDetails() {
        return "Employee details.";
    }
}

class Manager extends Employee {
    @Override
    String getDetails() {
        return "Manager details.";
    }
}

class Developer extends Employee {
    @Override
    String getDetails() {
        return "Developer details.";
    }
}

public class Main {
    public static void main(String[] args) {
        ArrayList<Employee> employees = new ArrayList<>();
        employees.add(new Manager());
        employees.add(new Developer());

        for (Employee employee : employees) {
            System.out.println(employee.getDetails()); // Polymorphic behavior
        }
    }
}
```
