## Here are the solutions to the exercises on **using the `this` keyword** in Java:

---

### **Solution 1: Referring to Instance Variables**
```java
class Employee {
    String name;
    double salary;

    void setDetails(String name, double salary) {
        this.name = name; // Refers to the instance variable
        this.salary = salary;
    }
}

public class Main {
    public static void main(String[] args) {
        Employee emp = new Employee();
        emp.setDetails("Alice", 50000);
        System.out.println("Name: " + emp.name);
        System.out.println("Salary: " + emp.salary);
    }
}
```

---

### **Solution 2: Invoking Current Class Constructor**
```java
class Student {
    String name;
    int rollNumber;

    Student(String name) {
        this.name = name;
    }

    Student(String name, int rollNumber) {
        this(name); // Invoking the single-parameter constructor
        this.rollNumber = rollNumber;
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student("John", 101);
        System.out.println("Name: " + student.name);
        System.out.println("Roll Number: " + student.rollNumber);
    }
}
```

---

### **Solution 3: Returning Current Class Instance**
```java
class Calculator {
    int result;

    Calculator add(int value) {
        this.result += value;
        return this; // Returning the current instance
    }

    Calculator subtract(int value) {
        this.result -= value;
        return this;
    }
}

public class Main {
    public static void main(String[] args) {
        Calculator calc = new Calculator();
        calc.add(10).subtract(5); // Method chaining
        System.out.println("Final Result: " + calc.result);
    }
}
```

### **Solution 4: Passing Current Class Instance as Argument**
```java
class Manager {
    String name;
    int departmentId;

    void printDetails(Manager obj) {
        System.out.println("Manager Name: " + obj.name);
        System.out.println("Department ID: " + obj.departmentId);
    }

    void display() {
        printDetails(this); // Passing current instance
    }
}

public class Main {
    public static void main(String[] args) {
        Manager mgr = new Manager();
        mgr.name = "David";
        mgr.departmentId = 202;
        mgr.display();
    }
}
```

### **Solution 5: Invoking Current Class Method**
```java
class Rectangle {
    double length, width;

    void setDimensions(double length, double width) {
        this.length = length;
        this.width = width;
        this.validateDimensions();
    }

    void validateDimensions() {
        if (length <= 0 || width <= 0) {
            this.length = 1.0;
            this.width = 1.0;
            System.out.println("Invalid dimensions. Resetting to default.");
        }
    }
}

public class Main {
    public static void main(String[] args) {
        Rectangle rect = new Rectangle();
        rect.setDimensions(5, -2); // Invalid dimensions
        System.out.println("Length: " + rect.length + ", Width: " + rect.width);
    }
}
```

### **Solution 6: Accessing Outer Class Members**
```java
class Car {
    private String model = "Tesla Model 3";

    class Engine {
        void printModel() {
            System.out.println("Car Model: " + Car.this.model); // Accessing outer class member
        }
    }
}

public class Main {
    public static void main(String[] args) {
        Car car = new Car();
        Car.Engine engine = car.new Engine();
        engine.printModel();
    }
}
```

### **Solution 8: Calling Current Class Method in Constructor**
```java
class Circle {
    double radius;

    Circle(double radius) {
        this.radius = radius;
        this.calculateArea(); // Calling current class method
    }

    void calculateArea() {
        double area = Math.PI * radius * radius;
        System.out.println("Circle Area: " + area);
    }
}

public class Main {
    public static void main(String[] args) {
        Circle circle = new Circle(5);
    }
}
```

### **Solution 9: Passing Current Instance to Another Class**
```java
class Person {
    String name;
    int age;

    Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    void validate() {
        Validator validator = new Validator();
        validator.validate(this); // Passing current instance
    }
}

class Validator {
    void validate(Person person) {
        if (person.age > 0) {
            System.out.println(person.name + " has valid age: " + person.age);
        } else {
            System.out.println(person.name + " has invalid age.");
        }
    }
}

public class Main {
    public static void main(String[] args) {
        Person person = new Person("John", 25);
        person.validate();
    }
}
```

### **Solution 10: Method Chaining with this**
```java
class Builder {
    String part1, part2, part3;

    Builder setPart1(String part1) {
        this.part1 = part1;
        return this;
    }

    Builder setPart2(String part2) {
        this.part2 = part2;
        return this;
    }

    Builder setPart3(String part3) {
        this.part3 = part3;
        return this;
    }

    void printParts() {
        System.out.println("Part1: " + part1 + ", Part2: " + part2 + ", Part3: " + part3);
    }
}

public class Main {
    public static void main(String[] args) {
        Builder builder = new Builder();
        builder.setPart1("A").setPart2("B").setPart3("C"); // Method chaining
        builder.printParts();
    }
}
```
