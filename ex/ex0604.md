#### **Solution 7: Reverse a String**
```java
public class Main {
    public static void main(String[] args) {
        String str = "Reverse Me";
        String reversed = "";

        for (int i = str.length() - 1; i >= 0; i--) {
            reversed += str.charAt(i);
        }

        System.out.println("Reversed String: " + reversed);
    }
}
```

#### **Solution 8: Count Occurrences of a Character**

```java
public class Main {
    public static void main(String[] args) {

        int count = 0;

        for (int i = 0; i < str.length(); i++) {
            if (str.charAt(i) == target) {
                count++;
            }
        }

        System.out.println("Occurrences of 's': " + count);
    }
}
```

#### **Solution 15: Capitalize Each Word**
```java
public class Main {
    public static void main(String[] args) {
        String sentence = "java is fun";
        String[] words = sentence.split(" ");
        StringBuilder capitalized = new StringBuilder();

        for (String word : words) {
            capitalized.append(Character.toUpperCase(word.charAt(0)))
                       .append(word.substring(1))
                       .append(" ");
        }

        System.out.println("Capitalized Sentence: " + capitalized.toString().trim());
    }
}
```

#### **Solution 17: Find Longest Word**
```java
public class Main {
    public static void main(String[] args) {
        String sentence = "The quick brown fox jumps over the lazy dog";
        String[] words = sentence.split(" ");
        String longestWord = "";

        for (String word : words) {
            if (word.length() > longestWord.length()) {
                longestWord = word;
            }
        }

        System.out.println("Longest word: " + longestWord);
    }
}
```

#### **Solution 18: Count Digits and Letters**
```java
public class Main {
    public static void main(String[] args) {
        String str = "Java123Programming456";
        int letters = 0, digits = 0;

        for (char ch : str.toCharArray()) {
            if (Character.isLetter(ch)) {
                letters++;
            } else if (Character.isDigit(ch)) {
                digits++;
            }
        }

        System.out.println("Letters: " + letters);
        System.out.println("Digits: " + digits);
    }
}
```
