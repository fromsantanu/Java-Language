# Loop Control
### **Basic Loop Control Questions**
1. **Using `break`**
   - Write a program to print numbers from 1 to 10, but stop the loop when the number is 5.

2. **Using `continue`**
   - Write a program to print all numbers from 1 to 10, but skip printing the number 5.

3. **Nested Loops with `break`**
   - Write a program to print a 5x5 grid of stars (`*`), but break the inner loop when the column number equals the row number.

4. **Nested Loops with `continue`**
   - Write a program to print a 5x5 grid of stars (`*`), but skip the star at the diagonal (i.e., when row == column).

5. **Exiting a Loop**
   - Write a program where the user inputs numbers continuously. Stop the loop if the user enters a negative number.

---

### **Intermediate Loop Control Questions**
6. **Find the First Multiple**
   - Write a program to find the first multiple of 7 in the range 1 to 50. Use `break` to exit the loop once the first multiple is found.

7. **Skip Multiples**
   - Write a program to print all numbers from 1 to 50 except multiples of 7. Use `continue` to skip the multiples.

8. **Nested Loops with Conditions**
   - Write a program to print a multiplication table (from 1 to 10), but skip rows where the multiplier is greater than 5 using `continue`.

9. **Prime Numbers with `break`**
   - Write a program to check if a number is prime using a `for` loop and `break` to exit the loop as soon as a factor is found.

10. **Print Triangle Pattern**
    - Write a program to print a triangle pattern of stars, but break out of the loop if the number of rows exceeds 5.

---

### **Advanced Loop Control Questions**
11. **Labelled `break`**
    - Write a program with nested loops to find a pair of numbers (x, y) such that x + y = 10, within the range 1 to 10. Use a labelled `break` to exit both loops once the pair is found.

12. **Labelled `continue`**
    - Write a program with nested loops to print all pairs (x, y) where x is odd and y is even in the range 1 to 5, skipping cases where x + y is divisible by 3. Use a labelled `continue`.

13. **Palindrome Search**
    - Write a program to find the first palindrome number in a given range using `break`.

14. **Odd-Even Counter with `continue`**
    - Write a program to count how many odd and even numbers exist in the range 1 to 20 using `continue` to skip the irrelevant numbers.

15. **Factorial with `break`**
    - Write a program to compute the factorial of a number using a loop and `break` the loop early if the number exceeds 10.

# Answers

Here are the answers to the 15 loop control-specific questions:

---

### **1. Using `break`**
```java
public class BreakExample {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i == 5) {
                break;
            }
            System.out.println(i);
        }
    }
}
```

---

### **2. Using `continue`**
```java
public class ContinueExample {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i == 5) {
                continue;
            }
            System.out.println(i);
        }
    }
}
```

---

### **3. Nested Loops with `break`**
```java
public class BreakNestedLoops {
    public static void main(String[] args) {
        for (int row = 1; row <= 5; row++) {
            for (int col = 1; col <= 5; col++) {
                if (col == row) {
                    break;
                }
                System.out.print("* ");
            }
            System.out.println();
        }
    }
}
```

### **4. Nested Loops with `continue`**
```java
public class ContinueNestedLoops {
    public static void main(String[] args) {
        for (int row = 1; row <= 5; row++) {
            for (int col = 1; col <= 5; col++) {
                if (col == row) {
                    continue;
                }
                System.out.print("* ");
            }
            System.out.println();
        }
    }
}
```

### **5. Exiting a Loop**
```java
import java.util.Scanner;

public class ExitLoop {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        while (true) {
            System.out.print("Enter a number (negative to exit): ");
            int number = sc.nextInt();
            if (number < 0) {
                break;
            }
        }
        System.out.println("Loop exited.");
    }
}
```

### **9. Prime Numbers with `break`**
```java
public class PrimeCheck {
    public static void main(String[] args) {
        int number = 29;
        boolean isPrime = true;
        for (int i = 2; i <= number / 2; i++) {
            if (number % i == 0) {
                isPrime = false;
                break;
            }
        }
        System.out.println(number + " is " + (isPrime ? "prime." : "not prime."));
    }
}
```

### **11. Labelled `break`**
```java
public class LabelledBreak {
    public static void main(String[] args) {
        outerLoop:
        for (int x = 1; x <= 10; x++) {
            for (int y = 1; y <= 10; y++) {
                if (x + y == 10) {
                    System.out.println("Pair found: (" + x + ", " + y + ")");
                    break outerLoop;
                }
            }
        }
    }
}
```

---

### **12. Labelled `continue`**
```java
public class LabelledContinue {
    public static void main(String[] args) {
        outerLoop:
        for (int x = 1; x <= 5; x++) {
            if (x % 2 == 0) continue;
            for (int y = 1; y <= 5; y++) {
                if (y % 2 != 0 || (x + y) % 3 == 0) {
                    continue outerLoop;
                }
                System.out.println("Pair: (" + x + ", " + y + ")");
            }
        }
    }
}
```

### **13. Palindrome Search**
```java
public class PalindromeSearch {
    public static void main(String[] args) {
        for (int i = 100; i <= 999; i++) {
            int number = i, reverse = 0, temp = number;
            while (temp > 0) {
                reverse = reverse * 10 + temp % 10;
                temp /= 10;
            }
            if (number == reverse) {
                System.out.println("First palindrome: " + number);
                break;
            }
        }
    }
}
```

### **14. Odd-Even Counter with `continue`**
```java
public class OddEvenCounter {
    public static void main(String[] args) {
        int oddCount = 0, evenCount = 0;
        for (int i = 1; i <= 20; i++) {
            if (i % 2 == 0) {
                evenCount++;
                continue;
            }
            oddCount++;
        }
        System.out.println("Odd count: " + oddCount);
        System.out.println("Even count: " + evenCount);
    }
}
```

### **15. Factorial with `break`**
```java
public class FactorialWithBreak {
    public static void main(String[] args) {
        int number = 10, factorial = 1;
        for (int i = 1; i <= number; i++) {
            if (i > 10) {
                break;
            }
            factorial *= i;
        }
        System.out.println("Factorial: " + factorial);
    }
}
```
