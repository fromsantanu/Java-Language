# **Loops in Java: `for`, `while`, and `do-while`**

Loops are a fundamental construct in programming that allow the repeated execution of a block of code as long as a specified condition holds true. Java provides three primary types of loops: `for`, `while`, and `do-while`. This chapter explores each type of loop, their syntax, and practical examples.

---

## **1. Why Use Loops?**

Loops help to:
1. **Reduce Code Repetition:** Avoid duplicating code for repetitive tasks.
2. **Automate Tasks:** Execute operations a fixed or variable number of times.
3. **Handle Dynamic Conditions:** Perform iterations based on changing inputs or conditions.

---

## **2. The `for` Loop**

The `for` loop is a control structure designed for definite iterations, where the number of iterations is known in advance.

### **Syntax**
```java
for (initialization; condition; update) {
    // Code to execute in each iteration
}
```

1. **Initialization**: Executed once, typically initializes a loop control variable.
2. **Condition**: Evaluated before each iteration; if `true`, the loop body executes.
3. **Update**: Modifies the loop control variable after each iteration.

---

### **Example: Counting Numbers**
```java
public class ForLoopExample {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println("Count: " + i);
        }
    }
}
```

**Output:**
```
Count: 1
Count: 2
Count: 3
Count: 4
Count: 5
```

---

### **Enhanced `for` Loop (For-Each Loop)**

The enhanced `for` loop is designed to iterate over arrays or collections.

**Syntax:**
```java
for (type variable : arrayOrCollection) {
    // Code to execute for each element
}
```

**Example: Iterating Over an Array**
```java
public class ForEachExample {
    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40};

        for (int num : numbers) {
            System.out.println("Number: " + num);
        }
    }
}
```

**Output:**
```
Number: 10
Number: 20
Number: 30
Number: 40
```

---

## **3. The `while` Loop**

The `while` loop is a control structure for indefinite iterations, where the number of iterations depends on a condition.

### **Syntax**
```java
while (condition) {
    // Code to execute while condition is true
}
```

1. **Condition**: Evaluated before each iteration. If `false`, the loop terminates.
2. **Body**: Executes repeatedly while the condition is `true`.

---

### **Example: Sum Until Limit**
```java
public class WhileLoopExample {
    public static void main(String[] args) {
        int sum = 0;
        int i = 1;

        while (i <= 5) {
            sum += i; // Add current value of i to sum
            i++;      // Increment i
        }

        System.out.println("Total sum: " + sum);
    }
}
```

**Output:**
```
Total sum: 15
```

---

### **Infinite `while` Loop**
An infinite loop occurs when the condition always evaluates to `true`.

**Example:**
```java
public class InfiniteWhileLoop {
    public static void main(String[] args) {
        while (true) {
            System.out.println("This loop runs forever!");
        }
    }
}
```

**Note:** Use `break` statements to exit infinite loops when necessary.

---

## **4. The `do-while` Loop**

The `do-while` loop is similar to the `while` loop but ensures that the loop body executes at least once, even if the condition is initially `false`.

### **Syntax**
```java
do {
    // Code to execute
} while (condition);
```

1. **Body**: Executes once before the condition is evaluated.
2. **Condition**: Evaluated after each iteration; if `true`, the loop continues.

---

### **Example: Input Validation**
```java
import java.util.Scanner;

public class DoWhileExample {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int number;

        do {
            System.out.print("Enter a number greater than 0: ");
            number = scanner.nextInt();
        } while (number <= 0);

        System.out.println("You entered: " + number);
    }
}
```

**Output Example:**
```
Enter a number greater than 0: -3
Enter a number greater than 0: 0
Enter a number greater than 0: 5
You entered: 5
```

---

## **5. Loop Control Statements**

### **5.1 `break` Statement**
- Exits the loop immediately, skipping the remaining iterations.

**Example: Stop on Condition**
```java
public class BreakExample {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i == 5) {
                break; // Exit the loop when i equals 5
            }
            System.out.println(i);
        }
    }
}
```

**Output:**
```
1
2
3
4
```

---

### **5.2 `continue` Statement**
- Skips the current iteration and moves to the next one.

**Example: Skip Odd Numbers**
```java
public class ContinueExample {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            if (i % 2 != 0) {
                continue; // Skip the iteration if i is odd
            }
            System.out.println(i);
        }
    }
}
```

**Output:**
```
2
4
```

---

## **6. Comparing Loops**

| **Feature**       | **`for` Loop**                      | **`while` Loop**               | **`do-while` Loop**            |
|--------------------|-------------------------------------|---------------------------------|--------------------------------|
| **Use Case**       | Definite iterations.               | Indefinite iterations.          | Executes at least once.       |
| **Condition Check**| Before each iteration.             | Before each iteration.          | After each iteration.         |
| **Control**        | Includes initialization, condition, and update in one line. | Requires external initialization and update. | Similar to `while`, but guarantees one execution. |

---

## **7. Nested Loops**

Loops can be nested to handle multidimensional operations.

**Example: Multiplication Table**
```java
public class NestedLoopExample {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            for (int j = 1; j <= 5; j++) {
                System.out.print(i * j + "\t");
            }
            System.out.println(); // New line after each row
        }
    }
}
```

**Output:**
```
1   2   3   4   5
2   4   6   8   10
3   6   9   12  15
4   8   12  16  20
5   10  15  20  25
```

## **8. Common Mistakes and Best Practices**

### **8.1 Common Mistakes**
1. **Infinite Loops:** Forgetting to update the loop variable in `while` and `for` loops.
2. **Off-by-One Errors:** Incorrect loop bounds or conditions.
3. **Skipping `do-while` Conditions:** Misplacing or misunderstanding `do-while` logic.

### **8.2 Best Practices**
1. Use `for` loops for predictable iterations.
2. Use `while` or `do-while` loops for condition-based iteration.
3. Avoid deeply nested loops; consider breaking into separate functions.
4. Comment on the purpose of the loop for better readability.

---

## **9. Summary**

- **`for` Loop:** Ideal for definite iterations with known bounds.
- **`while` Loop:** Suitable for condition-based iterations.
- **`do-while` Loop:** Ensures the body executes at least once.
- Use `break` to exit loops prematurely and `continue` to skip iterations.

Mastering loops enables efficient, concise, and powerful code structures for repetitive tasks in Java programming.
