# **Data Types and Variables in Java**

Java is a statically-typed language, meaning all variables must be declared with a specific data type before use. Understanding data types and variables is fundamental to Java programming, as they define how data is stored, manipulated, and accessed in memory. This chapter explores Java's data types and how to work with variables effectively.

---

## **1. Variables in Java**

A **variable** is a container for storing data during the execution of a program. Each variable in Java has a name, a type, and a value.

### **1.1. Declaring Variables**
A variable is declared using a data type followed by its name. Optionally, it can be initialized at the time of declaration.

```java
int age; // Declaration
age = 25; // Initialization
int height = 170; // Declaration and initialization
```

### **1.2. Types of Variables**
Java supports three main types of variables:
1. **Local Variables**: Declared inside a method or block and accessible only within that scope.
2. **Instance Variables**: Declared within a class but outside any method, constructor, or block. They are non-static and belong to an object.
3. **Static Variables**: Declared with the `static` keyword inside a class. They are shared among all instances of the class.

```java
class Example {
    int instanceVar = 10; // Instance variable
    static int staticVar = 20; // Static variable

    void display() {
        int localVar = 30; // Local variable
        System.out.println("Local Variable: " + localVar);
    }
}
```

## **2. Data Types in Java**

Java's data types specify the kind of values a variable can hold. They are divided into **primitive data types** and **non-primitive data types**.

---

### **2.1. Primitive Data Types**
Primitive data types are predefined by the language and represent simple values.

| **Type**      | **Size**   | **Range**                                | **Example**     |
|---------------|------------|------------------------------------------|-----------------|
| `byte`        | 1 byte     | -128 to 127                              | `byte b = 100;` |
| `short`       | 2 bytes    | -32,768 to 32,767                        | `short s = 5000;` |
| `int`         | 4 bytes    | -2^31 to 2^31-1                          | `int i = 100000;` |
| `long`        | 8 bytes    | -2^63 to 2^63-1                          | `long l = 100000L;` |
| `float`       | 4 bytes    | Approximately ±3.40282347E+38F           | `float f = 3.14f;` |
| `double`      | 8 bytes    | Approximately ±1.79769313486231570E+308  | `double d = 3.14159;` |
| `char`        | 2 bytes    | 0 to 65,535 (Unicode)                    | `char c = 'A';` |
| `boolean`     | 1 bit      | `true` or `false`                        | `boolean flag = true;` |

#### Notes:
- `float` and `double` are used for decimal numbers. Always append `f` or `F` for `float` and `d` or `D` for `double`.
- `char` is a single 16-bit Unicode character.
- `boolean` values are primarily used in conditional statements.

---

### **2.2. Non-Primitive Data Types**
Non-primitive (or reference) data types store references to objects and include:
- **Strings**: Sequence of characters.
- **Arrays**: Collection of elements of the same type.
- **Classes and Interfaces**: Custom types defined by the programmer.

Example:
```java
String name = "Java Programming";
int[] numbers = {1, 2, 3, 4, 5};
```

---

## **3. Variable Scope and Lifetime**

The scope of a variable determines where it can be accessed in the program.

### **3.1. Local Scope**
Variables declared inside a method or block have a local scope and are destroyed once the block ends.

```java
void display() {
    int localVar = 10; // Accessible only within this method
}
```

### **3.2. Instance Scope**
Instance variables are accessible as long as the object exists.

```java
class Example {
    int instanceVar; // Accessible within the object
}
```

### **3.3. Class Scope**
Static variables have a class-level scope and are shared across all instances of the class.

```java
class Example {
    static int staticVar; // Accessible using the class name
}
```

---

## **4. Type Conversion and Casting**

### **4.1. Implicit Type Conversion (Widening)**
- Automatically performed when converting a smaller data type to a larger one.
- No data loss occurs.

```java
int a = 10;
double b = a; // Implicit conversion
```

### **4.2. Explicit Type Casting (Narrowing)**
- Required when converting a larger data type to a smaller one.
- May result in data loss.

```java
double a = 10.5;
int b = (int) a; // Explicit casting
```

---

## **5. Constants in Java**

Use the `final` keyword to declare constants whose values cannot be changed.

```java
final double PI = 3.14159;
```

---

## **6. Default Values of Variables**

Variables in Java have default values only if they are instance or static variables. Local variables must be explicitly initialized.

| **Data Type** | **Default Value** |
|---------------|--------------------|
| `byte`        | `0`               |
| `short`       | `0`               |
| `int`         | `0`               |
| `long`        | `0L`              |
| `float`       | `0.0f`            |
| `double`      | `0.0d`            |
| `char`        | `'\u0000'`        |
| `boolean`     | `false`           |
| `String`/Objects | `null`         |

## **7. Example Program**

The following program demonstrates the use of variables and data types:

```java
public class DataTypesExample {
    // Instance variable
    int instanceVar = 42;

    // Static variable
    static String staticVar = "Java";

    public static void main(String[] args) {
        // Local variable
        double localVar = 3.14;

        // Printing variables
        System.out.println("Instance Variable: Not directly accessible in static context");
        System.out.println("Static Variable: " + staticVar);
        System.out.println("Local Variable: " + localVar);

        // Type casting
        int narrowedValue = (int) localVar;
        System.out.println("Narrowed Value: " + narrowedValue);

        // Constant
        final int CONSTANT_VALUE = 100;
        System.out.println("Constant: " + CONSTANT_VALUE);
    }
}
```

**Expected Output:**
```
Instance Variable: Not directly accessible in static context
Static Variable: Java
Local Variable: 3.14
Narrowed Value: 3
Constant: 100
```

---

## **8. Summary**

- Java variables are containers for data that must be declared with a specific type.
- Primitive data types store simple values, while non-primitive types handle objects and collections.
- Variables have different scopes and lifetimes: local, instance, or static.
- Constants are declared with the `final` keyword, ensuring immutability.
- Understanding data types and variable management is essential for writing efficient and error-free Java programs.
