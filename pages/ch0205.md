# **Input and Output in Java**

Input and output (I/O) operations are fundamental to any programming language, allowing programs to interact with users or other systems. In Java, **input** is typically handled through the `Scanner` class, while **output** is managed using the `System.out` stream. This chapter explores how Java manages I/O and provides examples for common use cases.

---

## **1. Input in Java**

### **1.1 Using the `Scanner` Class**
The `Scanner` class is part of the `java.util` package and is commonly used for reading user input from the console.

#### **Steps to Use `Scanner`:**
1. Import the `Scanner` class.
2. Create an instance of `Scanner`, passing `System.in` as an argument.
3. Use the appropriate method (e.g., `nextInt()`, `nextLine()`) to read input.

#### **Common Methods of `Scanner`**
| **Method**      | **Description**                                   |
|------------------|---------------------------------------------------|
| `next()`         | Reads a single word (token) as a `String`.         |
| `nextLine()`     | Reads an entire line of text as a `String`.        |
| `nextInt()`      | Reads an `int` value.                              |
| `nextDouble()`   | Reads a `double` value.                            |
| `nextBoolean()`  | Reads a `boolean` value.                           |
| `nextFloat()`    | Reads a `float` value.                             |
| `nextLong()`     | Reads a `long` value.                              |
| `nextShort()`    | Reads a `short` value.                             |

---

### **1.2 Example: Reading User Input**

```java
import java.util.Scanner;

public class InputExample {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = scanner.nextLine(); // Reads an entire line

        System.out.print("Enter your age: ");
        int age = scanner.nextInt(); // Reads an integer

        System.out.print("Enter your height (in meters): ");
        double height = scanner.nextDouble(); // Reads a double

        System.out.println("Hello, " + name + ". You are " + age + " years old and " + height + " meters tall.");
    }
}
```

**Output Example:**
```
Enter your name: Alice
Enter your age: 25
Enter your height (in meters): 1.7
Hello, Alice. You are 25 years old and 1.7 meters tall.
```

## **2. Output in Java**

### **2.1 Using `System.out`**

Java uses the `System.out` object, which is part of the `java.lang` package, to print output to the console. It supports the following methods:

| **Method**           | **Description**                                  |
|-----------------------|-------------------------------------------------|
| `print()`             | Outputs text without a newline.                 |
| `println()`           | Outputs text followed by a newline.             |
| `printf()`            | Outputs formatted text.                         |

---

### **2.2 Printing with `print()` and `println()`

- `print()`: Outputs text without moving to a new line.
- `println()`: Outputs text and moves the cursor to the next line.

**Example:**
```java
public class OutputExample {
    public static void main(String[] args) {
        System.out.print("Hello");
        System.out.print(" World!"); // Same line
        System.out.println();       // Moves to the next line
        System.out.println("Welcome to Java programming."); // New line
    }
}
```

**Output:**
```
Hello World!
Welcome to Java programming.
```

---

### **2.3 Formatted Output with `printf()`**

`printf()` allows precise control over formatting using format specifiers.

#### **Common Format Specifiers**
| **Specifier** | **Description**                      |
|---------------|--------------------------------------|
| `%d`          | Decimal integer                     |
| `%f`          | Floating-point number               |
| `%s`          | String                              |
| `%c`          | Character                           |
| `%b`          | Boolean                             |

**Example:**
```java
public class FormattedOutput {
    public static void main(String[] args) {
        String name = "Alice";
        int age = 25;
        double height = 1.7;

        System.out.printf("Name: %s, Age: %d, Height: %.2f meters\n", name, age, height);
    }
}
```

**Output:**
```
Name: Alice, Age: 25, Height: 1.70 meters
```

## **3. Combining Input and Output**

Here’s an example program combining both input and output:

```java
import java.util.Scanner;

public class CombineIO {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter a number: ");
        int num = scanner.nextInt();

        System.out.print("Enter another number: ");
        int num2 = scanner.nextInt();

        int sum = num + num2;

        System.out.println("The sum is: " + sum);
    }
}
```

**Output Example:**
```
Enter a number: 10
Enter another number: 20
The sum is: 30
```

## **4. Advanced Input and Output**

### **4.1 Reading Characters**
You can use `Scanner` or `System.in.read()` for character input.

**Example with `Scanner`:**
```java
Scanner scanner = new Scanner(System.in);
System.out.print("Enter a character: ");
char c = scanner.next().charAt(0);
System.out.println("You entered: " + c);
```

---

### **4.2 Redirecting Input and Output**
You can redirect input and output streams for testing or logging.

**Redirecting Output to a File:**
```java
import java.io.FileOutputStream;
import java.io.PrintStream;

public class RedirectOutput {
    public static void main(String[] args) throws Exception {
        PrintStream fileOut = new PrintStream(new FileOutputStream("output.txt"));
        System.setOut(fileOut);
        System.out.println("This will be written to the file.");
    }
}
```

## **5. Common Errors and Tips**

### **5.1 Common Errors**
- **`InputMismatchException`**: Occurs when input type does not match the expected type (e.g., entering text when an integer is expected).
  **Solution**: Validate input or use `scanner.nextLine()` to read raw input and parse it manually.
- **Unwanted Skipping**: After using `nextInt()` or `nextDouble()`, the newline character (`\n`) might remain in the buffer.
  **Solution**: Use an extra `scanner.nextLine()` to clear the buffer.

**Example:**
```java
Scanner scanner = new Scanner(System.in);
System.out.print("Enter an integer: ");
int num = scanner.nextInt();
scanner.nextLine(); // Clear the buffer
System.out.print("Enter a string: ");
String text = scanner.nextLine();
System.out.println("You entered: " + text);
```

---

### **5.2 Tips for Efficient I/O**
1. Use `BufferedReader` for faster input in competitive programming.
2. Use `try-with-resources` to automatically close the `Scanner` object.
3. Use `printf()` for well-formatted output in reports or tables.

## **6. Summary**

- **Input**: The `Scanner` class simplifies reading various types of input.
- **Output**: `System.out.print`, `System.out.println`, and `System.out.printf` allow for flexible text output.
- Combining input and output enables interactive programs.
- Handling errors like `InputMismatchException` ensures robust input handling.

By mastering input and output, you can build dynamic and user-friendly Java programs.
