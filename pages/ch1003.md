# **ArrayList, LinkedList, HashSet, TreeSet, HashMap, and TreeMap in Java**

The Java Collections Framework includes a variety of data structures that cater to different needs for managing data. This chapter provides an in-depth look at some of the most commonly used collection classes: **`ArrayList`**, **`LinkedList`**, **`HashSet`**, **`TreeSet`**, **`HashMap`**, and **`TreeMap`**.

---

## **1. `ArrayList`**

### **1.1. Description**
- **`ArrayList`** is a resizable array implementation of the **`List`** interface.
- Maintains the order of insertion.
- Allows duplicate elements.

### **1.2. Key Features**
- Fast random access using indices.
- Slower insertion and deletion compared to `LinkedList`.

### **1.3. Common Methods**
| **Method**        | **Description**                                      |
|-------------------|------------------------------------------------------|
| `add(E e)`        | Appends an element to the end of the list.           |
| `get(int index)`  | Retrieves the element at the specified index.        |
| `remove(int index)` | Removes the element at the specified index.         |
| `size()`          | Returns the number of elements in the list.          |

### **1.4. Example**
```java
import java.util.*;

public class ArrayListExample {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();
        list.add("Java");
        list.add("Python");
        list.add("C++");
        
        System.out.println("ArrayList: " + list);
        list.remove(1);
        System.out.println("After removal: " + list);
    }
}
```

**Output**:
```
ArrayList: [Java, Python, C++]
After removal: [Java, C++]
```

## **2. `LinkedList`**

### **2.1. Description**
- **`LinkedList`** is a doubly-linked list implementation of the **`List`** and **`Deque`** interfaces.
- Maintains the order of insertion.

### **2.2. Key Features**
- Efficient insertion and deletion operations.
- Slower random access compared to `ArrayList`.

### **2.3. Common Methods**
| **Method**       | **Description**                                      |
|------------------|------------------------------------------------------|
| `add(E e)`       | Appends an element to the end of the list.           |
| `addFirst(E e)`  | Inserts an element at the beginning of the list.     |
| `addLast(E e)`   | Appends an element to the end of the list.           |
| `removeFirst()`  | Removes the first element of the list.               |

### **2.4. Example**
```java
import java.util.*;

public class LinkedListExample {
    public static void main(String[] args) {
        LinkedList<String> list = new LinkedList<>();
        list.add("Java");
        list.add("Python");
        list.addFirst("C++");
        
        System.out.println("LinkedList: " + list);
        list.removeLast();
        System.out.println("After removal: " + list);
    }
}
```

**Output**:
```
LinkedList: [C++, Java, Python]
After removal: [C++, Java]
```

## **3. `HashSet`**

### **3.1. Description**
- **`HashSet`** is a hash table-based implementation of the **`Set`** interface.
- Does not allow duplicate elements.
- No guaranteed order of elements.

### **3.2. Key Features**
- Fast lookup and insertion.
- No duplicate elements.

### **3.3. Common Methods**
| **Method**         | **Description**                              |
|--------------------|----------------------------------------------|
| `add(E e)`         | Adds the specified element to the set.       |
| `remove(Object o)` | Removes the specified element from the set.  |
| `contains(Object o)` | Checks if the set contains the specified element. |

### **3.4. Example**
```java
import java.util.*;

public class HashSetExample {
    public static void main(String[] args) {
        HashSet<String> set = new HashSet<>();
        set.add("Java");
        set.add("Python");
        set.add("Java"); // Duplicate ignored
        
        System.out.println("HashSet: " + set);
    }
}
```

**Output**:
```
HashSet: [Python, Java]
```

## **4. `TreeSet`**

### **4.1. Description**
- **`TreeSet`** is a red-black tree-based implementation of the **`Set`** interface.
- Does not allow duplicate elements.
- Maintains sorted order of elements.

### **4.2. Key Features**
- Sorted elements in natural or custom order.
- Slower than `HashSet`.

### **4.3. Common Methods**
| **Method**      | **Description**                                |
|-----------------|------------------------------------------------|
| `add(E e)`      | Adds the specified element to the set.         |
| `first()`       | Retrieves the first (lowest) element.          |
| `last()`        | Retrieves the last (highest) element.          |
| `subSet(E from, E to)` | Returns a portion of the set.            |

### **4.4. Example**
```java
import java.util.*;

public class TreeSetExample {
    public static void main(String[] args) {
        TreeSet<Integer> set = new TreeSet<>();
        set.add(10);
        set.add(5);
        set.add(20);
        
        System.out.println("TreeSet: " + set);
        System.out.println("First: " + set.first());
        System.out.println("Last: " + set.last());
    }
}
```

**Output**:
```
TreeSet: [5, 10, 20]
First: 5
Last: 20
```

## **5. `HashMap`**

### **5.1. Description**
- **`HashMap`** is a hash table-based implementation of the **`Map`** interface.
- Stores key-value pairs.
- Does not guarantee order of keys.

### **5.2. Key Features**
- Fast lookups for keys.
- Allows null keys and values.

### **5.3. Common Methods**
| **Method**         | **Description**                                      |
|--------------------|------------------------------------------------------|
| `put(K key, V value)` | Associates the specified value with the key.       |
| `get(Object key)`  | Retrieves the value associated with the key.         |
| `remove(Object key)` | Removes the key-value pair for the specified key.   |

### **5.4. Example**
```java
import java.util.*;

public class HashMapExample {
    public static void main(String[] args) {
        HashMap<Integer, String> map = new HashMap<>();
        map.put(1, "Java");
        map.put(2, "Python");
        
        System.out.println("HashMap: " + map);
        System.out.println("Value for key 1: " + map.get(1));
    }
}
```

**Output**:
```
HashMap: {1=Java, 2=Python}
Value for key 1: Java
```

## **6. `TreeMap`**

### **6.1. Description**
- **`TreeMap`** is a red-black tree-based implementation of the **`Map`** interface.
- Stores key-value pairs in sorted order of keys.

### **6.2. Key Features**
- Maintains sorted order.
- Slower than `HashMap`.

### **6.3. Common Methods**
| **Method**           | **Description**                                      |
|----------------------|------------------------------------------------------|
| `put(K key, V value)` | Associates the specified value with the key.         |
| `firstKey()`         | Retrieves the first (lowest) key.                    |
| `lastKey()`          | Retrieves the last (highest) key.                    |

### **6.4. Example**
```java
import java.util.*;

public class TreeMapExample {
    public static void main(String[] args) {
        TreeMap<Integer, String> map = new TreeMap<>();
        map.put(2, "Python");
        map.put(1, "Java");
        map.put(3, "C++");
        
        System.out.println("TreeMap: " + map);
        System.out.println("First Key: " + map.firstKey());
        System.out.println("Last Key: " + map.lastKey());
    }
}
```

**Output**:
```
TreeMap: {1=Java, 2=Python, 3=C++}
First Key: 1
Last Key: 3
```

## **7. Comparison of Classes**

| **Feature**          | **ArrayList** | **LinkedList** | **HashSet** | **TreeSet** | **HashMap** | **TreeMap** |
|-----------------------|---------------|----------------|-------------|-------------|-------------|-------------|
| **Order**            | Maintains insertion order | Maintains insertion order | Unordered | Sorted | Unordered | Sorted |
| **Duplicates**       | Allowed       | Allowed        | Not Allowed | Not Allowed | Keys: Not Allowed, Values: Allowed | Keys: Not Allowed, Values: Allowed |
| **Performance**      | Fast random access, slower insertion/deletion | Faster insertion/deletion, slower random access | Fast lookups | Slower lookups, sorted | Fast lookups | Slower lookups, sorted |

---

## **8. Summary**

- **`ArrayList`** and **`LinkedList`** are used for ordered collections.
- **`HashSet`** and **`TreeSet`** are used for unique elements, with `TreeSet` maintaining a sorted order.
- **`HashMap`** and **`TreeMap`** are used for key-value pairs, with `TreeMap` maintaining a sorted order of keys.

Choosing the right class depends on the specific requirements of your application, such as performance, ordering, and duplication constraints.
