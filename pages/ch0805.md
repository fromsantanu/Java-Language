# **`throw` and `throws` Keywords in Java**

Java provides the **`throw`** and **`throws`** keywords to handle exceptions programmatically. These keywords enable developers to generate and propagate exceptions, ensuring better control and clarity in error handling.

---

## **1. Overview of `throw` and `throws`**

| **Keyword** | **Purpose**                                                                 |
|-------------|-----------------------------------------------------------------------------|
| **`throw`** | Used to explicitly generate an exception.                                   |
| **`throws`** | Declares exceptions that a method might throw, requiring the caller to handle them. |

---

## **2. The `throw` Keyword**

### **2.1. Purpose**
- The `throw` keyword is used to explicitly create and throw an exception at runtime.

### **2.2. Syntax**
```java
throw new ExceptionType("Exception message");
```

---

### **2.3. Example: Throwing an Exception**

**Code Example:**
```java
public class ThrowExample {
    public static void main(String[] args) {
        int age = 15;

        if (age < 18) {
            throw new IllegalArgumentException("Age must be 18 or older.");
        }

        System.out.println("Access granted.");
    }
}
```

**Output:**
```
Exception in thread "main" java.lang.IllegalArgumentException: Age must be 18 or older.
```

---

### **2.4. Common Scenarios for `throw`**
1. **Input Validation**:
   - Throw exceptions when input values are invalid.

   **Example**:
   ```java
   public void validateInput(int value) {
       if (value <= 0) {
           throw new IllegalArgumentException("Value must be greater than 0.");
       }
   }
   ```

2. **Custom Exception Handling**:
   - Use `throw` with custom exceptions for specific application requirements.

   **Example**:
   ```java
   public class CustomException extends Exception {
       public CustomException(String message) {
           super(message);
       }
   }

   public void performAction(boolean valid) throws CustomException {
       if (!valid) {
           throw new CustomException("Custom exception occurred.");
       }
   }
   ```

---

## **3. The `throws` Keyword**

### **3.1. Purpose**
- The `throws` keyword is used in method declarations to specify the exceptions that the method can throw.
- It informs the caller that the method might throw an exception and forces them to handle it.

### **3.2. Syntax**
```java
returnType methodName(parameters) throws ExceptionType1, ExceptionType2 {
    // Method body
}
```

---

### **3.3. Example: Declaring Exceptions with `throws`**

**Code Example:**
```java
import java.io.IOException;

public class ThrowsExample {
    public static void main(String[] args) {
        try {
            readFile();
        } catch (IOException e) {
            System.out.println("Caught exception: " + e.getMessage());
        }
    }

    public static void readFile() throws IOException {
        throw new IOException("File not found.");
    }
}
```

**Output:**
```
Caught exception: File not found.
```

---

### **3.4. Declaring Multiple Exceptions**

You can declare multiple exceptions using a comma-separated list.

**Example**:
```java
public void processFile() throws IOException, NullPointerException {
    // Code that may throw IOException or NullPointerException
}
```

---

## **4. Key Differences Between `throw` and `throws`**

| **Aspect**               | **`throw`**                                            | **`throws`**                                      |
|---------------------------|-------------------------------------------------------|--------------------------------------------------|
| **Purpose**               | Used to explicitly throw an exception.                | Declares exceptions that a method might throw.   |
| **Placement**             | Inside the method body.                               | In the method signature.                         |
| **Scope**                 | Refers to a single exception instance.                | Refers to one or more exception types.           |
| **Example**               | `throw new Exception("Error");`                       | `void method() throws Exception { ... }`         |

---

## **5. Combining `throw` and `throws`**

**Code Example:**
```java
import java.io.IOException;

public class ThrowThrowsExample {
    public static void main(String[] args) {
        try {
            processFile();
        } catch (IOException e) {
            System.out.println("Caught exception: " + e.getMessage());
        }
    }

    public static void processFile() throws IOException {
        throw new IOException("Error processing file.");
    }
}
```

**Output:**
```
Caught exception: Error processing file.
```

**Explanation**:
- The method `processFile()` declares that it throws an `IOException` using `throws`.
- Inside the method, the exception is explicitly thrown using `throw`.

---

## **6. Best Practices**

### **6.1. For `throw`**
1. **Validate Inputs**:
   - Use `throw` to reject invalid inputs with meaningful exception messages.

2. **Use Custom Exceptions**:
   - Create custom exceptions for specific application needs.

   **Example**:
   ```java
   public class InvalidAgeException extends Exception {
       public InvalidAgeException(String message) {
           super(message);
       }
   }
   ```

3. **Avoid Overuse**:
   - Only use `throw` for exceptional situations, not for normal control flow.

---

### **6.2. For `throws`**
1. **Declare Only Necessary Exceptions**:
   - Avoid declaring generic exceptions like `Exception` unless unavoidable.
   
2. **Handle Checked Exceptions**:
   - If a method declares checked exceptions, ensure the caller handles them appropriately.

3. **Use Specific Exceptions**:
   - Declare precise exceptions that convey meaningful information about the error.

---

## **7. Common Mistakes**

1. **Catching Unchecked Exceptions**:
   - Unchecked exceptions (`RuntimeException`) do not need to be declared using `throws`.

   **Incorrect**:
   ```java
   public void method() throws NullPointerException {
       // Unnecessary
   }
   ```

2. **Overusing Generic Exceptions**:
   - Avoid catching or throwing generic exceptions like `Exception` or `Throwable` unless absolutely necessary.

   **Better Approach**:
   - Use specific exceptions like `IOException` or `ArithmeticException`.

---

## **8. Summary**

### **`throw`**
- Generates an exception explicitly.
- Syntax: `throw new ExceptionType("Message");`
- Used for input validation, custom exceptions, and error reporting.

### **`throws`**
- Declares exceptions a method might throw.
- Syntax: `methodName() throws ExceptionType1, ExceptionType2 { ... }`
- Forces the caller to handle or propagate exceptions.

### **Key Practices**
- Use `throw` to explicitly signal errors.
- Use `throws` to declare exceptions and enforce handling.
- Ensure proper error messages and specific exception types for clarity.

By understanding and using the `throw` and `throws` keywords effectively, developers can build robust error-handling mechanisms in Java applications.
