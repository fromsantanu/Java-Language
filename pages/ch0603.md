# **Strings in Java**

Strings are one of the most commonly used data types in Java. The **String** class provides a way to handle and manipulate text, while **StringBuilder** and **StringBuffer** offer optimized approaches for modifying strings. This chapter explores these classes, their differences, and practical use cases.

---

## **1. What is a String in Java?**

A **string** in Java is a sequence of characters. Strings are immutable, meaning their content cannot be changed after creation.

---

### **1.1. Creating Strings**

Strings can be created using:
1. **String Literals**:
   - Stored in the **String Pool** to save memory by reusing existing strings.
   - **Example:**
     ```java
     String s1 = "Hello";
     String s2 = "Hello"; // Reuses the same string in the pool
     ```

2. **Using the `new` Keyword**:
   - Creates a new string in the heap memory, even if an identical string exists in the pool.
   - **Example:**
     ```java
     String s1 = new String("Hello");
     String s2 = new String("Hello"); // Creates a new object
     ```

---

### **1.2. Basic String Operations**

**Example:**
```java
public class StringExample {
    public static void main(String[] args) {
        String greeting = "Hello, World!";
        System.out.println("Length: " + greeting.length());
        System.out.println("Character at index 7: " + greeting.charAt(7));
        System.out.println("Substring: " + greeting.substring(7));
        System.out.println("Replaced: " + greeting.replace("World", "Java"));
    }
}
```

**Output:**
```
Length: 13
Character at index 7: W
Substring: World!
Replaced: Hello, Java!
```

## **2. String Class**

The **String class** in Java provides numerous methods for string manipulation.

### **2.1. Common Methods**

| **Method**                | **Description**                                  | **Example**                                      |
|---------------------------|--------------------------------------------------|-------------------------------------------------|
| `length()`                | Returns the length of the string.                | `"Hello".length()` → `5`                        |
| `charAt(int index)`       | Returns the character at the specified index.    | `"Hello".charAt(1)` → `'e'`                     |
| `substring(int begin)`    | Returns the substring starting from the index.   | `"Hello".substring(1)` → `"ello"`              |
| `substring(int, int)`     | Returns substring from begin to end (exclusive). | `"Hello".substring(1, 4)` → `"ell"`            |
| `toLowerCase()`           | Converts the string to lowercase.                | `"Hello".toLowerCase()` → `"hello"`            |
| `toUpperCase()`           | Converts the string to uppercase.                | `"Hello".toUpperCase()` → `"HELLO"`            |
| `trim()`                  | Removes leading and trailing whitespace.         | `" Hello ".trim()` → `"Hello"`                 |
| `replace(char, char)`     | Replaces all occurrences of a character.         | `"Hello".replace('l', 'p')` → `"Heppo"`        |
| `equals(String)`          | Checks if two strings are equal.                 | `"Hello".equals("hello")` → `false`            |
| `equalsIgnoreCase(String)`| Compares strings ignoring case.                  | `"Hello".equalsIgnoreCase("hello")` → `true`   |
| `contains(CharSequence)`  | Checks if string contains the sequence.          | `"Hello".contains("ell")` → `true`             |
| `split(String regex)`     | Splits string into an array by regex.            | `"a,b,c".split(",")` → `["a", "b", "c"]`       |

---

### **2.2. Immutability of Strings**

Strings are immutable, meaning modifications result in the creation of a new string.

**Example:**
```java
public class StringImmutability {
    public static void main(String[] args) {
        String s1 = "Hello";
        String s2 = s1.concat(" World");
        System.out.println("Original: " + s1);
        System.out.println("Modified: " + s2);
    }
}
```

**Output:**
```
Original: Hello
Modified: Hello World
```

## **3. StringBuilder**

The **StringBuilder** class provides a mutable sequence of characters. It is faster than the `String` class for modifying strings, as it does not create new objects.

---

### **3.1. Common Methods**

| **Method**         | **Description**                                  | **Example**                                 |
|---------------------|--------------------------------------------------|---------------------------------------------|
| `append(String)`    | Adds the string to the end.                      | `sb.append("World")` → `"HelloWorld"`      |
| `insert(int, String)`| Inserts the string at the specified position.    | `sb.insert(5, " ")` → `"Hello World"`      |
| `replace(int, int, String)`| Replaces substring in range.                | `sb.replace(6, 11, "Java")` → `"Hello Java"`|
| `delete(int, int)`  | Removes characters in range.                     | `sb.delete(5, 6)` → `"HelloWorld"`         |
| `reverse()`         | Reverses the string.                             | `sb.reverse()` → `"dlroWolleH"`           |

---

### **3.2. Example: StringBuilder**

```java
public class StringBuilderExample {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder("Hello");
        sb.append(" World");
        sb.insert(5, ",");
        sb.replace(7, 12, "Java");
        sb.reverse();

        System.out.println(sb);
    }
}
```

**Output:**
```
avaJ ,olleH
```

---

## **4. StringBuffer**

The **StringBuffer** class is similar to `StringBuilder` but is thread-safe, meaning it can be used in multi-threaded environments.

---

### **4.1. Key Differences Between StringBuilder and StringBuffer**

| **Aspect**           | **StringBuilder**                 | **StringBuffer**                  |
|-----------------------|-----------------------------------|------------------------------------|
| **Thread-Safety**     | Not thread-safe (faster).         | Thread-safe (synchronized).        |
| **Performance**       | Faster due to no synchronization.| Slower due to synchronization.     |

---

### **4.2. Example: StringBuffer**

```java
public class StringBufferExample {
    public static void main(String[] args) {
        StringBuffer sb = new StringBuffer("Hello");
        sb.append(" World");
        sb.insert(5, ",");
        sb.replace(7, 12, "Java");

        System.out.println(sb);
    }
}
```

**Output:**
```
Hello, Java
```

---

## **5. Choosing Between String, StringBuilder, and StringBuffer**

| **Use Case**                    | **Preferred Class** |
|----------------------------------|---------------------|
| Immutable strings (read-only).  | `String`            |
| Mutable strings (single-threaded)| `StringBuilder`     |
| Mutable strings (multi-threaded)| `StringBuffer`      |

---

## **6. Practical Example: Performance Comparison**

**Example:**
```java
public class StringPerformance {
    public static void main(String[] args) {
        long startTime, endTime;

        // String
        startTime = System.currentTimeMillis();
        String s = "";
        for (int i = 0; i < 10000; i++) {
            s += i;
        }
        endTime = System.currentTimeMillis();
        System.out.println("Time taken by String: " + (endTime - startTime) + "ms");

        // StringBuilder
        startTime = System.currentTimeMillis();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 10000; i++) {
            sb.append(i);
        }
        endTime = System.currentTimeMillis();
        System.out.println("Time taken by StringBuilder: " + (endTime - startTime) + "ms");
    }
}
```

**Output (example):**
```
Time taken by String: 300ms
Time taken by StringBuilder: 5ms
```

---

## **7. Summary**

- **String**:
  - Immutable and stored in the String Pool.
  - Best for operations where modification is not required.
- **StringBuilder**:
  - Mutable and faster for string manipulation.
  - Ideal for single-threaded environments.
- **StringBuffer**:
  - Mutable and thread-safe.
  - Suitable for multi-threaded applications.

By understanding these classes and their operations, developers can choose the right tool for efficient string manipulation in Java.
