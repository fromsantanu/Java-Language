# **String Manipulation Methods in Java**

String manipulation is an essential part of programming, and Java provides a rich set of methods in the **String** class to handle and modify strings efficiently. These methods allow developers to search, modify, split, concatenate, and transform strings.

---

## **1. Overview of String Manipulation**

Strings in Java are **immutable**, meaning they cannot be changed after creation. Any operation on a string creates a new string object. This immutability ensures security and thread safety.

### **String Class**
The `String` class provides numerous methods for manipulating strings. It is part of the `java.lang` package and does not require any import statement.

---

## **2. Common String Manipulation Methods**

### **2.1. Length of a String**

The `length()` method returns the number of characters in the string.

**Example:**
```java
public class LengthExample {
    public static void main(String[] args) {
        String str = "Hello, World!";
        System.out.println("Length: " + str.length());
    }
}
```

**Output:**
```
Length: 13
```

---

### **2.2. Character Access**

The `charAt(int index)` method retrieves the character at the specified index.

**Example:**
```java
public class CharAtExample {
    public static void main(String[] args) {
        String str = "Java";
        System.out.println("Character at index 2: " + str.charAt(2));
    }
}
```

**Output:**
```
Character at index 2: v
```

---

### **2.3. Substring**

The `substring(int start)` and `substring(int start, int end)` methods extract a part of the string.

**Example:**
```java
public class SubstringExample {
    public static void main(String[] args) {
        String str = "Hello, World!";
        System.out.println("Substring (7 to end): " + str.substring(7));
        System.out.println("Substring (0 to 5): " + str.substring(0, 5));
    }
}
```

**Output:**
```
Substring (7 to end): World!
Substring (0 to 5): Hello
```

---

### **2.4. String Concatenation**

The `concat(String str)` method appends one string to another.

**Example:**
```java
public class ConcatExample {
    public static void main(String[] args) {
        String str1 = "Hello";
        String str2 = " World";
        System.out.println(str1.concat(str2));
    }
}
```

**Output:**
```
Hello World
```

---

### **2.5. Replace Characters**

The `replace(char oldChar, char newChar)` or `replace(CharSequence target, CharSequence replacement)` method replaces occurrences of a character or sequence.

**Example:**
```java
public class ReplaceExample {
    public static void main(String[] args) {
        String str = "Java is fun";
        System.out.println(str.replace('a', 'o'));
        System.out.println(str.replace("fun", "awesome"));
    }
}
```

**Output:**
```
Jovo is fun
Java is awesome
```

---

### **2.6. Case Conversion**

- `toUpperCase()`: Converts all characters to uppercase.
- `toLowerCase()`: Converts all characters to lowercase.

**Example:**
```java
public class CaseConversionExample {
    public static void main(String[] args) {
        String str = "Java Programming";
        System.out.println("Uppercase: " + str.toUpperCase());
        System.out.println("Lowercase: " + str.toLowerCase());
    }
}
```

**Output:**
```
Uppercase: JAVA PROGRAMMING
Lowercase: java programming
```

---

### **2.7. Trim Whitespace**

The `trim()` method removes leading and trailing spaces.

**Example:**
```java
public class TrimExample {
    public static void main(String[] args) {
        String str = "  Hello, Java!  ";
        System.out.println("Trimmed: '" + str.trim() + "'");
    }
}
```

**Output:**
```
Trimmed: 'Hello, Java!'
```

---

### **2.8. String Split**

The `split(String regex)` method splits a string into an array of substrings based on a delimiter.

**Example:**
```java
import java.util.Arrays;

public class SplitExample {
    public static void main(String[] args) {
        String str = "apple,banana,cherry";
        String[] fruits = str.split(",");
        System.out.println(Arrays.toString(fruits));
    }
}
```

**Output:**
```
[apple, banana, cherry]
```

---

### **2.9. String Contains**

The `contains(CharSequence s)` method checks if a string contains a specific sequence of characters.

**Example:**
```java
public class ContainsExample {
    public static void main(String[] args) {
        String str = "Java Programming";
        System.out.println("Contains 'Java': " + str.contains("Java"));
        System.out.println("Contains 'Python': " + str.contains("Python"));
    }
}
```

**Output:**
```
Contains 'Java': true
Contains 'Python': false
```

---

### **2.10. String Equality**

- `equals(String str)`: Checks if two strings are equal.
- `equalsIgnoreCase(String str)`: Checks equality ignoring case.

**Example:**
```java
public class EqualityExample {
    public static void main(String[] args) {
        String str1 = "Java";
        String str2 = "java";
        System.out.println("Equals: " + str1.equals(str2));
        System.out.println("Equals Ignore Case: " + str1.equalsIgnoreCase(str2));
    }
}
```

**Output:**
```
Equals: false
Equals Ignore Case: true
```

## **3. Advanced String Manipulation**

### **3.1. Reverse a String**

**Example:**
```java
public class ReverseExample {
    public static void main(String[] args) {
        String str = "Hello";
        String reversed = new StringBuilder(str).reverse().toString();
        System.out.println("Reversed: " + reversed);
    }
}
```

**Output:**
```
Reversed: olleH
```

---

### **3.2. Count Characters**

**Example:**
```java
public class CountCharacters {
    public static void main(String[] args) {
        String str = "Java Programming";
        char target = 'a';
        long count = str.chars().filter(ch -> ch == target).count();
        System.out.println("Count of 'a': " + count);
    }
}
```

**Output:**
```
Count of 'a': 3
```

---

### **3.3. Check Palindrome**

**Example:**
```java
public class PalindromeExample {
    public static void main(String[] args) {
        String str = "madam";
        boolean isPalindrome = str.equals(new StringBuilder(str).reverse().toString());
        System.out.println("Is Palindrome: " + isPalindrome);
    }
}
```

**Output:**
```
Is Palindrome: true
```

## **4. Performance Considerations**

- **String**: Immutable and slow for repeated modifications.
- **StringBuilder**: Mutable and efficient for single-threaded modifications.
- **StringBuffer**: Thread-safe but slower than `StringBuilder`.

**Example: StringBuilder for Performance:**
```java
public class PerformanceExample {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 10000; i++) {
            sb.append(i);
        }
        System.out.println("Length: " + sb.length());
    }
}
```
