# **Conditional Statements in Java: `if`, `if-else`, and Nested `if-else`**

Conditional statements are fundamental to decision-making in programming. In Java, these statements allow programs to execute different blocks of code based on certain conditions. This chapter explores the usage of `if`, `if-else`, and nested `if-else` statements in Java, with examples to illustrate each concept.

---

## **1. The `if` Statement**

The `if` statement evaluates a boolean condition. If the condition evaluates to `true`, the block of code inside the `if` statement is executed.

### **Syntax**
```java
if (condition) {
    // Code to execute if condition is true
}
```

### **Example**
```java
public class IfExample {
    public static void main(String[] args) {
        int number = 10;

        if (number > 5) {
            System.out.println("The number is greater than 5.");
        }
    }
}
```

**Output:**
```
The number is greater than 5.
```

---

## **2. The `if-else` Statement**

The `if-else` statement provides an alternate block of code to execute if the condition evaluates to `false`.

### **Syntax**
```java
if (condition) {
    // Code to execute if condition is true
} else {
    // Code to execute if condition is false
}
```

### **Example**
```java
public class IfElseExample {
    public static void main(String[] args) {
        int number = 3;

        if (number % 2 == 0) {
            System.out.println("The number is even.");
        } else {
            System.out.println("The number is odd.");
        }
    }
}
```

**Output:**
```
The number is odd.
```

---

## **3. The Nested `if-else` Statement**

A nested `if-else` statement is an `if-else` statement inside another `if` or `else` block. This allows for checking multiple conditions in a structured manner.

### **Syntax**
```java
if (condition1) {
    // Code to execute if condition1 is true
    if (condition2) {
        // Code to execute if condition2 is true
    } else {
        // Code to execute if condition2 is false
    }
} else {
    // Code to execute if condition1 is false
}
```

### **Example**
```java
public class NestedIfElseExample {
    public static void main(String[] args) {
        int number = 0;

        if (number > 0) {
            System.out.println("The number is positive.");
        } else {
            if (number < 0) {
                System.out.println("The number is negative.");
            } else {
                System.out.println("The number is zero.");
            }
        }
    }
}
```

**Output:**
```
The number is zero.
```

---

## **4. Multiple `if-else` Conditions**

For checking multiple conditions, we can use multiple `if-else` statements in sequence.

### **Syntax**
```java
if (condition1) {
    // Code to execute if condition1 is true
} else if (condition2) {
    // Code to execute if condition2 is true
} else {
    // Code to execute if none of the conditions are true
}
```

### **Example**
```java
public class MultipleIfElseExample {
    public static void main(String[] args) {
        int marks = 85;

        if (marks >= 90) {
            System.out.println("Grade: A");
        } else if (marks >= 75) {
            System.out.println("Grade: B");
        } else if (marks >= 50) {
            System.out.println("Grade: C");
        } else {
            System.out.println("Grade: F");
        }
    }
}
```

**Output:**
```
Grade: B
```

## **5. Common Pitfalls and Best Practices**

### **5.1 Common Pitfalls**
1. **Missing Braces:** Always use braces `{}` for clarity, even for single statements.
   ```java
   // Avoid
   if (condition) 
       statement; // Only one statement is controlled by the `if`
       otherStatement; // Not part of the `if` block
   ```

2. **Overusing Nested `if-else`:** Deeply nested conditions can make code hard to read. Use `else if` or switch to alternative logic where possible.

3. **Condition Errors:** Ensure conditions are logically sound to avoid incorrect outcomes.

### **5.2 Best Practices**
1. **Use Descriptive Conditions:** Write conditions that are self-explanatory.
   ```java
   if (age > 18) { // Clear condition
       System.out.println("Eligible to vote");
   }
   ```

2. **Simplify Complex Logic:** Break down complex conditions into smaller, readable parts.

3. **Avoid Redundant Conditions:** Ensure that conditions in `else if` are necessary and mutually exclusive.

## **6. Real-World Example: Login Validation**

```java
import java.util.Scanner;

public class LoginExample {
    public static void main(String[] args) {
        String username = "admin";
        String password = "password123";

        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter username: ");
        String inputUsername = scanner.nextLine();

        System.out.print("Enter password: ");
        String inputPassword = scanner.nextLine();

        if (username.equals(inputUsername)) {
            if (password.equals(inputPassword)) {
                System.out.println("Login successful!");
            } else {
                System.out.println("Incorrect password.");
            }
        } else {
            System.out.println("Username not found.");
        }
    }
}
```

**Example Output 1:**
```
Enter username: admin
Enter password: password123
Login successful!
```

**Example Output 2:**
```
Enter username: user
Enter password: password123
Username not found.
```

---

## **7. Summary**

- **`if` Statement:** Executes a block of code if the condition is `true`.
- **`if-else` Statement:** Provides an alternative block of code if the condition is `false`.
- **Nested `if-else`:** Handles multiple conditions by nesting one conditional statement inside another.
- **`else if`:** Useful for handling multiple mutually exclusive conditions.

Mastering conditional statements like `if`, `if-else`, and nested `if-else` allows developers to write dynamic and logical programs that respond to different inputs and scenarios effectively.
