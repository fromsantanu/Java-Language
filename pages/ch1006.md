# **Comparable and Comparator Interfaces in Java**

Sorting is a fundamental operation in programming. Java provides two interfaces, **Comparable** and **Comparator**, to define and customize the sorting order of objects. These interfaces are part of the **Java Collections Framework** and allow sorting to be performed in a natural or custom order.

---

## **1. Comparable Interface**

### **1.1. What is Comparable?**
The **Comparable** interface is used to define the **natural order** of objects. Classes implementing this interface must override the `compareTo()` method to specify how objects should be compared.

### **1.2. Key Points**
- **Package**: `java.lang`
- **Method**: `int compareTo(T o)`
- Used by methods like `Collections.sort()` to sort lists.

### **1.3. Method Signature**
```java
int compareTo(T o);
```

- **Returns**:
  - A negative integer if the current object is less than the specified object.
  - Zero if the current object is equal to the specified object.
  - A positive integer if the current object is greater than the specified object.

---

### **1.4. Example: Implementing Comparable**
```java
import java.util.*;

class Student implements Comparable<Student> {
    int id;
    String name;

    public Student(int id, String name) {
        this.id = id;
        this.name = name;
    }

    @Override
    public int compareTo(Student other) {
        return this.name.compareTo(other.name); // Compare by name
    }

    @Override
    public String toString() {
        return "Student{id=" + id + ", name='" + name + "'}";
    }
}

public class ComparableExample {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>();
        students.add(new Student(3, "Alice"));
        students.add(new Student(1, "Charlie"));
        students.add(new Student(2, "Bob"));

        Collections.sort(students); // Uses compareTo()
        System.out.println("Sorted by name: " + students);
    }
}
```

**Output**:
```
Sorted by name: [Student{id=3, name='Alice'}, Student{id=2, name='Bob'}, Student{id=1, name='Charlie'}]
```

---

## **2. Comparator Interface**

### **2.1. What is Comparator?**
The **Comparator** interface is used to define **custom order** for sorting objects. Unlike `Comparable`, it does not require modifying the class of the objects being sorted.

### **2.2. Key Points**
- **Package**: `java.util`
- **Method**: `int compare(T o1, T o2)`
- Multiple comparators can be created for different sorting criteria.

### **2.3. Method Signature**
```java
int compare(T o1, T o2);
```

- **Returns**:
  - A negative integer if `o1` is less than `o2`.
  - Zero if `o1` is equal to `o2`.
  - A positive integer if `o1` is greater than `o2`.

---

### **2.4. Example: Implementing Comparator**
```java
import java.util.*;

class Student {
    int id;
    String name;

    public Student(int id, String name) {
        this.id = id;
        this.name = name;
    }

    @Override
    public String toString() {
        return "Student{id=" + id + ", name='" + name + "'}";
    }
}

class SortById implements Comparator<Student> {
    @Override
    public int compare(Student s1, Student s2) {
        return Integer.compare(s1.id, s2.id); // Compare by ID
    }
}

class SortByName implements Comparator<Student> {
    @Override
    public int compare(Student s1, Student s2) {
        return s1.name.compareTo(s2.name); // Compare by Name
    }
}

public class ComparatorExample {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>();
        students.add(new Student(3, "Alice"));
        students.add(new Student(1, "Charlie"));
        students.add(new Student(2, "Bob"));

        Collections.sort(students, new SortById());
        System.out.println("Sorted by ID: " + students);

        Collections.sort(students, new SortByName());
        System.out.println("Sorted by Name: " + students);
    }
}
```

**Output**:
```
Sorted by ID: [Student{id=1, name='Charlie'}, Student{id=2, name='Bob'}, Student{id=3, name='Alice'}]
Sorted by Name: [Student{id=3, name='Alice'}, Student{id=2, name='Bob'}, Student{id=1, name='Charlie'}]
```

---

## **3. Key Differences Between Comparable and Comparator**

| **Aspect**         | **Comparable**                      | **Comparator**                     |
|---------------------|-------------------------------------|-------------------------------------|
| **Purpose**         | Defines natural order of objects.  | Defines custom order of objects.   |
| **Package**         | `java.lang`                       | `java.util`                        |
| **Method**          | `compareTo(T o)`                  | `compare(T o1, T o2)`              |
| **Changes Required**| Requires changes to the class.     | Does not modify the class.         |
| **Usage**           | Single sorting criterion.          | Multiple sorting criteria.         |

---

## **4. Sorting with Lambda Expressions (Java 8+)**

In Java 8 and later, lambda expressions simplify the use of `Comparator`.

#### **Example: Sorting with Lambda**
```java
import java.util.*;

class Student {
    int id;
    String name;

    public Student(int id, String name) {
        this.id = id;
        this.name = name;
    }

    @Override
    public String toString() {
        return "Student{id=" + id + ", name='" + name + "'}";
    }
}

public class LambdaComparatorExample {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>();
        students.add(new Student(3, "Alice"));
        students.add(new Student(1, "Charlie"));
        students.add(new Student(2, "Bob"));

        // Sort by ID
        students.sort((s1, s2) -> Integer.compare(s1.id, s2.id));
        System.out.println("Sorted by ID: " + students);

        // Sort by Name
        students.sort((s1, s2) -> s1.name.compareTo(s2.name));
        System.out.println("Sorted by Name: " + students);
    }
}
```

**Output**:
```
Sorted by ID: [Student{id=1, name='Charlie'}, Student{id=2, name='Bob'}, Student{id=3, name='Alice'}]
Sorted by Name: [Student{id=3, name='Alice'}, Student{id=2, name='Bob'}, Student{id=1, name='Charlie'}]
```

---

## **5. When to Use Comparable vs Comparator**

### **Use `Comparable` When:**
- A single, natural ordering is sufficient.
- You control the class implementation.

### **Use `Comparator` When:**
- Multiple sorting orders are needed.
- You cannot modify the class (e.g., classes from third-party libraries).

---

## **6. Summary**

| **Feature**             | **Comparable**                    | **Comparator**                   |
|-------------------------|-----------------------------------|-----------------------------------|
| **Interface Location**  | `java.lang`                     | `java.util`                      |
| **Method**              | `compareTo(T o)`                | `compare(T o1, T o2)`            |
| **Flexibility**         | Limited to one sorting order.    | Supports multiple sorting orders.|
| **Ease of Use**         | Straightforward for natural order.| Ideal for custom and multiple criteria. |

By leveraging **Comparable** and **Comparator** effectively, Java developers can handle a wide range of sorting requirements with flexibility and precision.
