# **Java Built-in Packages**

Java provides a rich set of built-in packages that contain classes and interfaces to support various programming needs. These packages simplify development by providing pre-written code for common tasks such as handling input/output, data structures, networking, concurrency, and more.

---

## **1. What Are Built-in Packages?**

Built-in packages are part of the Java Development Kit (JDK) and include classes and interfaces that developers can use directly in their programs. They are organized into namespaces to group related functionality.

---

## **2. Commonly Used Built-in Packages**

### **2.1. `java.lang`**
- **Description**: Provides classes that are fundamental to Java programming, such as `String`, `Math`, `Object`, and `System`.
- **Special Feature**: This package is implicitly imported, so you don’t need to explicitly import it.

**Key Classes**:
- `Object`: The root class of the Java hierarchy.
- `String`: Represents sequences of characters.
- `Math`: Provides mathematical functions like `sqrt`, `pow`, and constants like `PI`.
- `System`: Contains methods for standard input/output and interacting with the environment.

**Example**:
```java
public class JavaLangExample {
    public static void main(String[] args) {
        String message = "Hello, Java!";
        System.out.println(message.toUpperCase());

        double squareRoot = Math.sqrt(16);
        System.out.println("Square root of 16: " + squareRoot);
    }
}
```

---

### **2.2. `java.util`**
- **Description**: Contains utility classes for data structures, date and time, random number generation, and more.
- **Use Case**: Managing collections, working with dates, and generating random numbers.

**Key Classes**:
- `ArrayList`, `HashMap`, `HashSet`: Data structure classes.
- `Date`, `Calendar`: Classes for date manipulation.
- `Random`: Generates random numbers.
- `Scanner`: Reads user input.

**Example**:
```java
import java.util.*;

public class JavaUtilExample {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();
        list.add("Java");
        list.add("Python");
        list.add("C++");
        System.out.println("Programming Languages: " + list);

        Random random = new Random();
        System.out.println("Random number: " + random.nextInt(100));
    }
}
```

---

### **2.3. `java.io`**
- **Description**: Provides classes for input and output operations, such as reading from and writing to files, streams, and consoles.
- **Use Case**: File handling and stream operations.

**Key Classes**:
- `File`: Represents file and directory paths.
- `FileReader`, `FileWriter`: Classes for file reading and writing.
- `BufferedReader`, `BufferedWriter`: Efficient reading and writing.
- `InputStream`, `OutputStream`: For byte stream operations.

**Example**:
```java
import java.io.*;

public class JavaIoExample {
    public static void main(String[] args) {
        try {
            FileWriter writer = new FileWriter("example.txt");
            writer.write("Hello, File Handling in Java!");
            writer.close();
            System.out.println("File written successfully.");
        } catch (IOException e) {
            System.out.println("An error occurred: " + e.getMessage());
        }
    }
}
```

---

### **2.4. `java.net`**
- **Description**: Supports networking operations such as handling URLs, sockets, and HTTP connections.
- **Use Case**: Building networked applications.

**Key Classes**:
- `URL`: Represents a Uniform Resource Locator.
- `Socket`, `ServerSocket`: Implements TCP socket communication.
- `HttpURLConnection`: Manages HTTP requests.

**Example**:
```java
import java.net.*;

public class JavaNetExample {
    public static void main(String[] args) {
        try {
            URL url = new URL("https://www.example.com");
            System.out.println("Protocol: " + url.getProtocol());
            System.out.println("Host: " + url.getHost());
        } catch (MalformedURLException e) {
            System.out.println("Invalid URL: " + e.getMessage());
        }
    }
}
```

---

### **2.5. `java.sql`**
- **Description**: Provides classes for interacting with relational databases using JDBC (Java Database Connectivity).
- **Use Case**: Database connectivity and executing SQL queries.

**Key Classes**:
- `Connection`: Represents a connection to the database.
- `Statement`: Executes static SQL statements.
- `ResultSet`: Retrieves query results.
- `PreparedStatement`: Executes parameterized SQL statements.

**Example**:
```java
import java.sql.*;

public class JavaSqlExample {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/mydb";
        String user = "root";
        String password = "password";

        try (Connection connection = DriverManager.getConnection(url, user, password)) {
            System.out.println("Database connected successfully.");
        } catch (SQLException e) {
            System.out.println("Database connection failed: " + e.getMessage());
        }
    }
}
```

---

### **2.6. `java.time`**
- **Description**: Introduced in Java 8, it provides a modern API for date and time manipulation.
- **Use Case**: Handling dates and times in a thread-safe and immutable way.

**Key Classes**:
- `LocalDate`, `LocalTime`, `LocalDateTime`: Represent dates and times.
- `Duration`, `Period`: Represent time-based and date-based amounts.
- `DateTimeFormatter`: Formats date-time objects.

**Example**:
```java
import java.time.*;

public class JavaTimeExample {
    public static void main(String[] args) {
        LocalDate date = LocalDate.now();
        LocalTime time = LocalTime.now();
        System.out.println("Current Date: " + date);
        System.out.println("Current Time: " + time);
    }
}
```

---

### **2.7. `java.nio`**
- **Description**: Provides classes for non-blocking I/O operations, buffer management, and file handling.
- **Use Case**: High-performance file and network operations.

**Key Classes**:
- `Path`, `Files`: Handle file paths and operations.
- `ByteBuffer`, `CharBuffer`: Manage data in buffers.
- `Channels`: Represent connections for I/O operations.

**Example**:
```java
import java.nio.file.*;

public class JavaNioExample {
    public static void main(String[] args) {
        Path path = Paths.get("example.txt");
        try {
            Files.writeString(path, "Hello, NIO!");
            System.out.println("File written successfully.");
        } catch (IOException e) {
            System.out.println("Error writing file: " + e.getMessage());
        }
    }
}
```

## **3. Accessing Built-in Packages**

To use classes from built-in packages:
1. **Import a Specific Class**:
   ```java
   import java.util.Scanner;
   ```
2. **Import All Classes in a Package**:
   ```java
   import java.util.*;
   ```
3. **Use Fully Qualified Names** (Optional):
   ```java
   public class Example {
       java.util.Scanner scanner = new java.util.Scanner(System.in);
   }
   ```

## **4. Summary**

### **Key Built-in Packages**

|---------------|------------------------------------------------|------------------------------------------------|
| `java.lang`   | Core classes fundamental to Java programming.  | `Object`, `String`, `Math`, `System`           |

| `java.io`     | Input and output operations.                   | `File`, `FileReader`, `BufferedReader`         |
| `java.net`    | Networking and communication.                  | `URL`, `Socket`, `HttpURLConnection`           |

### **Best Practices**
- Import only what you need to avoid clutter and inefficiency.
- Use modern packages (`java.time`, `java.nio`) for better performance and ease of use.
- Refer to the [Java API Documentation](https://docs.oracle.com/javase/8/docs/api/) for detailed information.

By understanding and using Java's built-in packages, developers can simplify coding tasks, enhance productivity, and build robust applications efficiently.
