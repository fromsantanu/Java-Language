# **Reading and Writing Files Using File I/O Classes**

File I/O (Input/Output) operations in Java allow reading data from and writing data to files. Java provides several classes in the **`java.io`** package for handling these operations. This chapter focuses on using `FileReader`, `FileWriter`, `BufferedReader`, and `BufferedWriter`.

---

## **1. FileReader and FileWriter**

### **1.1. FileReader**

The **`FileReader`** class is used to read data from files. It reads character data and is a convenient class for reading text files.

#### **Key Methods of FileReader**
| **Method**      | **Description**                                             |
|------------------|-------------------------------------------------------------|
| `int read()`     | Reads a single character and returns it as an integer. Returns `-1` at the end of the file. |
| `int read(char[] cbuf)` | Reads characters into an array and returns the number of characters read. |
| `void close()`   | Closes the file reader and releases system resources.       |

#### **Example: Reading a File Using FileReader**
```java
import java.io.*;

public class FileReaderExample {
    public static void main(String[] args) {
        try (FileReader reader = new FileReader("example.txt")) {
            int character;
            while ((character = reader.read()) != -1) {
                System.out.print((char) character);
            }
        } catch (IOException e) {
            System.out.println("An error occurred: " + e.getMessage());
        }
    }
}
```

---

### **1.2. FileWriter**

The **`FileWriter`** class is used to write data to files. It writes character data and is suitable for writing text files.

#### **Key Methods of FileWriter**
| **Method**         | **Description**                                     |
|---------------------|-----------------------------------------------------|
| `void write(int c)` | Writes a single character to the file.              |
| `void write(String str)` | Writes a string to the file.                   |
| `void flush()`      | Flushes the stream and forces any buffered output to be written. |
| `void close()`      | Closes the file writer and releases system resources.|

#### **Example: Writing to a File Using FileWriter**
```java
import java.io.*;

public class FileWriterExample {
    public static void main(String[] args) {
        try (FileWriter writer = new FileWriter("output.txt")) {
            writer.write("Hello, FileWriter!");
            System.out.println("Data written successfully.");
        } catch (IOException e) {
            System.out.println("An error occurred: " + e.getMessage());
        }
    }
}
```

---

## **2. BufferedReader and BufferedWriter**

### **2.1. BufferedReader**

The **`BufferedReader`** class reads text from a character-input stream, buffering characters to provide efficient reading.

#### **Key Methods of BufferedReader**
| **Method**            | **Description**                                        |
|------------------------|--------------------------------------------------------|
| `String readLine()`    | Reads a line of text and returns it as a string. Returns `null` at the end of the file. |
| `void close()`         | Closes the reader and releases system resources.       |

#### **Example: Reading a File Using BufferedReader**
```java
import java.io.*;

public class BufferedReaderExample {
    public static void main(String[] args) {
        try (BufferedReader reader = new BufferedReader(new FileReader("example.txt"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            System.out.println("An error occurred: " + e.getMessage());
        }
    }
}
```

---

### **2.2. BufferedWriter**

The **`BufferedWriter`** class writes text to a character-output stream, buffering characters to provide efficient writing.

#### **Key Methods of BufferedWriter**
| **Method**             | **Description**                                        |
|-------------------------|--------------------------------------------------------|
| `void write(String str)`| Writes a string to the file.                           |
| `void newLine()`        | Writes a newline character.                            |
| `void close()`          | Closes the writer and releases system resources.       |

#### **Example: Writing to a File Using BufferedWriter**
```java
import java.io.*;

public class BufferedWriterExample {
    public static void main(String[] args) {
        try (BufferedWriter writer = new BufferedWriter(new FileWriter("output.txt"))) {
            writer.write("Hello, BufferedWriter!");
            writer.newLine();
            writer.write("Writing efficiently with buffering.");
            System.out.println("Data written successfully.");
        } catch (IOException e) {
            System.out.println("An error occurred: " + e.getMessage());
        }
    }
}
```

## **3. Combining FileReader and BufferedReader**

Using `BufferedReader` with `FileReader` improves performance for reading large files.

#### **Example: Reading Large Files Efficiently**
```java
import java.io.*;

public class CombinedReaderExample {
    public static void main(String[] args) {
        try (BufferedReader reader = new BufferedReader(new FileReader("largefile.txt"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            System.out.println("An error occurred: " + e.getMessage());
        }
    }
}
```

---

## **4. Combining FileWriter and BufferedWriter**

Using `BufferedWriter` with `FileWriter` improves performance for writing large amounts of data.

#### **Example: Writing Large Files Efficiently**
```java
import java.io.*;

public class CombinedWriterExample {
    public static void main(String[] args) {
        try (BufferedWriter writer = new BufferedWriter(new FileWriter("largeoutput.txt"))) {
            for (int i = 1; i <= 100; i++) {
                writer.write("Line " + i);
                writer.newLine();
            }
            System.out.println("Data written successfully.");
        } catch (IOException e) {
            System.out.println("An error occurred: " + e.getMessage());
        }
    }
}
```

## **5. Summary of Classes**

| **Class**        | **Purpose**                      | **Best Use Case**                       |
|-------------------|----------------------------------|-----------------------------------------|
| `FileReader`      | Reads character data from a file. | Reading text files in a simple way.     |
| `FileWriter`      | Writes character data to a file. | Writing text files in a simple way.     |
| `BufferedReader`  | Reads text efficiently by buffering. | Reading large text files line by line. |
| `BufferedWriter`  | Writes text efficiently by buffering. | Writing large text files efficiently.  |

---

## **6. Best Practices**

1. **Use Buffered Classes for Efficiency**:
   - Always prefer `BufferedReader` and `BufferedWriter` for large files.

2. **Use Try-with-Resources**:
   - Automatically closes resources, preventing resource leaks.

3. **Handle Exceptions Properly**:
   - Catch and log exceptions for troubleshooting.

4. **Avoid Hardcoding File Paths**:
   - Use relative paths or configuration files for better portability.

---

## **7. Summary**

Java's File I/O classes, such as `FileReader`, `FileWriter`, `BufferedReader`, and `BufferedWriter`, provide efficient ways to handle file operations. By understanding their usage and combining them effectively, developers can create robust applications that handle file data with ease and performance.
