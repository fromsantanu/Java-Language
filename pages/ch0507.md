# **Encapsulation and Access Modifiers in Java**

**Encapsulation** and **access modifiers** are foundational concepts in Java that promote data security and modularity in object-oriented programming. Encapsulation is the process of bundling data (fields) and behavior (methods) into a single unit (class) while controlling access to the internal details using access modifiers.

---

## **1. What is Encapsulation?**

**Encapsulation** is a mechanism of restricting direct access to the fields of a class and providing controlled access through methods. It hides the implementation details of a class and exposes only the necessary functionalities.

---

### **Key Features of Encapsulation**
1. **Data Hiding**: Prevents direct access to class members from outside.
2. **Controlled Access**: Provides getters and setters for accessing and modifying private fields.
3. **Improved Maintainability**: Reduces coupling and makes code easier to modify and maintain.
4. **Enhanced Security**: Protects sensitive data from unintended changes.

---

### **Example: Encapsulation in Action**

```java
public class BankAccount {
    private double balance; // Private field

    // Constructor
    public BankAccount(double initialBalance) {
        if (initialBalance >= 0) {
            this.balance = initialBalance;
        }
    }

    // Getter method
    public double getBalance() {
        return balance;
    }

    // Setter method
    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    // Additional behavior
    public void withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
        } else {
            System.out.println("Invalid withdrawal amount");
        }
    }
}

public class Main {
    public static void main(String[] args) {
        BankAccount account = new BankAccount(1000);
        account.deposit(500);
        account.withdraw(200);
        System.out.println("Current balance: " + account.getBalance());
    }
}
```

**Output:**
```
Current balance: 1300.0
```

**Explanation:**
- The `balance` field is private, ensuring it cannot be accessed or modified directly from outside the class.
- Public methods `getBalance`, `deposit`, and `withdraw` provide controlled access to the `balance` field.

---

## **2. Access Modifiers**

**Access modifiers** in Java determine the visibility and accessibility of fields, methods, and constructors. They are essential for implementing encapsulation effectively.

### **Types of Access Modifiers**

| **Modifier**   | **Class** | **Package** | **Subclass** | **World**   |
|-----------------|-----------|-------------|--------------|-------------|
| `public`       | Yes       | Yes         | Yes          | Yes         |
| `protected`    | Yes       | Yes         | Yes          | No          |
| (default)      | Yes       | Yes         | No           | No          |
| `private`      | Yes       | No          | No           | No          |

---

### **2.1. Public Access Modifier**

- Fields, methods, or constructors declared as `public` are accessible from any class.
- Use it when the member should be globally accessible.

**Example:**
```java
public class PublicExample {
    public String message = "Public Access";

    public void displayMessage() {
        System.out.println(message);
    }
}
```

**Usage in another class:**
```java
public class Main {
    public static void main(String[] args) {
        PublicExample obj = new PublicExample();
        obj.displayMessage(); // Accessible
    }
}
```

---

### **2.2. Private Access Modifier**

- Fields, methods, or constructors declared as `private` are accessible only within the same class.
- Use it to enforce data hiding.

**Example:**
```java
public class PrivateExample {
    private String secret = "Private Access";

    private void displaySecret() {
        System.out.println(secret);
    }

    public void show() {
        displaySecret(); // Accessible within the class
    }
}
```

**Usage in another class:**
```java
public class Main {
    public static void main(String[] args) {
        PrivateExample obj = new PrivateExample();
        // obj.secret; // Compilation Error
        obj.show(); // Indirect access through a public method
    }
}
```

---

### **2.3. Protected Access Modifier**

- Fields, methods, or constructors declared as `protected` are accessible within the same package and by subclasses, even if they are in a different package.

**Example:**
```java
public class Parent {
    protected String protectedMessage = "Protected Access";

    protected void displayMessage() {
        System.out.println(protectedMessage);
    }
}

public class Child extends Parent {
    public void show() {
        displayMessage(); // Accessible in subclass
    }
}
```

---

### **2.4. Default (Package-Private) Access Modifier**

- If no access modifier is specified, the member has **default** access.
- Fields, methods, or constructors are accessible only within the same package.

**Example:**
```java
class DefaultExample {
    String message = "Default Access";

    void displayMessage() {
        System.out.println(message);
    }
}
```

**Usage in another class within the same package:**
```java
public class Main {
    public static void main(String[] args) {
        DefaultExample obj = new DefaultExample();
        obj.displayMessage(); // Accessible
    }
}
```

---

## **3. Combining Encapsulation and Access Modifiers**

Access modifiers play a crucial role in implementing encapsulation. Here's how they work together:

1. **Use `private` for Fields**:
   - Prevents direct access to sensitive data.
   - Ensures data integrity by exposing fields only through controlled methods.

2. **Provide Getters and Setters**:
   - Use `public` or `protected` methods to allow controlled access to private fields.
   - Validate inputs or enforce rules before modifying fields.

---

### **Example: Encapsulation with Access Modifiers**

```java
public class Student {
    private String name;
    private int age;

    // Getter for name
    public String getName() {
        return name;
    }

    // Setter for name
    public void setName(String name) {
        this.name = name;
    }

    // Getter for age
    public int getAge() {
        return age;
    }

    // Setter for age with validation
    public void setAge(int age) {
        if (age > 0) {
            this.age = age;
        } else {
            System.out.println("Age must be positive.");
        }
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();
        student.setName("Alice");
        student.setAge(20);

        System.out.println("Name: " + student.getName());
        System.out.println("Age: " + student.getAge());
    }
}
```

**Output:**
```
Name: Alice
Age: 20
```

---

## **4. Benefits of Encapsulation and Access Modifiers**

1. **Improved Security**:
   - Protects sensitive data from unintended access or modification.

2. **Flexibility**:
   - Changes to internal implementation do not affect external code.
   
3. **Code Reusability**:
   - Provides reusable and modular classes.

4. **Better Maintainability**:
   - Reduces dependencies and minimizes bugs.

---

## **5. Best Practices**

1. **Always Use `private` for Fields**:
   - Protects data integrity and enforces encapsulation.

2. **Provide Controlled Access**:
   - Use public or protected methods for accessing private fields.

3. **Minimize Use of `public`**:
   - Avoid exposing implementation details unnecessarily.

4. **Use `protected` for Inheritance**:
   - Use `protected` to allow access in subclasses while restricting general access.

---

## **6. Summary**

- **Encapsulation**:
  - Bundles data and methods into a single unit and restricts direct access to fields.
  - Achieved through private fields and public/protected getters and setters.
- **Access Modifiers**:
  - Control visibility and accessibility of fields, methods, and constructors.
  - Types: `public`, `private`, `protected`, and default.
- **Best Practices**:
  - Use `private` fields and provide controlled access using public methods.

Encapsulation and access modifiers together ensure that classes are modular, secure, and maintainable, forming the backbone of object-oriented programming in Java.
