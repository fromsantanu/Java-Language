# **Inheritance and Method Overriding in Java**

**Inheritance** and **method overriding** are key features of object-oriented programming (OOP) in Java. Inheritance allows a class to acquire properties and behaviors from another class, enabling code reuse and creating a hierarchical relationship between classes. Method overriding lets a subclass provide a specific implementation of a method already defined in its superclass.

---

## **1. What is Inheritance?**

**Inheritance** is the mechanism by which one class (subclass) derives the properties and behaviors of another class (superclass). It is used to promote code reuse and establish a parent-child relationship between classes.

### **Key Features**
1. **Code Reusability**: Common features are defined in the superclass and reused by subclasses.
2. **Hierarchical Relationships**: Models "is-a" relationships between objects.
3. **Overriding Behavior**: Subclasses can modify or extend the behavior of superclass methods.

---

### **Syntax**
```java
class Superclass {
    // Fields and methods of the superclass
}

class Subclass extends Superclass {
    // Additional fields and methods
}
```

---

### **Example: Basic Inheritance**
```java
// Superclass
class Animal {
    void eat() {
        System.out.println("This animal eats food.");
    }
}

// Subclass
class Dog extends Animal {
    void bark() {
        System.out.println("The dog barks.");
    }
}

public class InheritanceExample {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.eat();  // Inherited from Animal
        dog.bark(); // Defined in Dog
    }
}
```

**Output:**
```
This animal eats food.
The dog barks.
```

## **2. Types of Inheritance**

### **2.1. Single Inheritance**
A subclass inherits from one superclass.

**Example:**
```java
class Parent {
    void display() {
        System.out.println("Parent class method.");
    }
}

class Child extends Parent {
}

public class SingleInheritance {
    public static void main(String[] args) {
        Child child = new Child();
        child.display();
    }
}
```

---

### **2.2. Multilevel Inheritance**
A subclass inherits from another subclass.

**Example:**
```java
class Grandparent {
    void show() {
        System.out.println("Grandparent class.");
    }
}

class Parent extends Grandparent {
}

class Child extends Parent {
}

public class MultilevelInheritance {
    public static void main(String[] args) {
        Child child = new Child();
        child.show(); // Inherited from Grandparent
    }
}
```

---

### **2.3. Hierarchical Inheritance**
Multiple subclasses inherit from the same superclass.

**Example:**
```java
class Animal {
    void eat() {
        System.out.println("Animal eats food.");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks.");
    }
}

class Cat extends Animal {
    void meow() {
        System.out.println("Cat meows.");
    }
}

public class HierarchicalInheritance {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.eat();
        dog.bark();

        Cat cat = new Cat();
        cat.eat();
        cat.meow();
    }
}
```

---

## **3. Method Overriding**

**Method overriding** occurs when a subclass provides a specific implementation for a method already defined in its superclass. The method in the subclass must have the same name, return type, and parameters as the method in the superclass.

---

### **Key Features**
1. **Same Signature**: The method name, return type, and parameter list must match.
2. **Run-Time Polymorphism**: The method to be executed is determined at runtime.
3. **@Override Annotation**: Indicates that a method is being overridden.

---

### **Syntax**
```java
@Override
returnType methodName(parameters) {
    // Subclass-specific implementation
}
```

---

### **Example: Method Overriding**
```java
class Animal {
    void sound() {
        System.out.println("This animal makes a sound.");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("The dog barks.");
    }
}

public class MethodOverridingExample {
    public static void main(String[] args) {
        Animal animal = new Dog();
        animal.sound(); // Calls the overridden method in Dog
    }
}
```

**Output:**
```
The dog barks.
```

---

## **4. Accessing Superclass Methods**

The **`super` keyword** is used to call a superclass method or constructor from a subclass.

### **Example: Using `super`**
```java
class Animal {
    void sound() {
        System.out.println("This animal makes a sound.");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        super.sound(); // Call superclass method
        System.out.println("The dog barks.");
    }
}

public class SuperKeywordExample {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.sound();
    }
}
```

**Output:**
```
This animal makes a sound.
The dog barks.
```

---

## **5. Method Overriding vs Method Overloading**

| **Aspect**              | **Method Overriding**                     | **Method Overloading**                      |
|--------------------------|-------------------------------------------|---------------------------------------------|
| **Definition**           | Subclass provides a specific implementation of a superclass method. | Multiple methods with the same name but different parameters in the same class. |
| **Parameters**           | Must have the same parameters.            | Must have different parameter lists.        |
| **Return Type**          | Must be the same or covariant.            | Can vary.                                   |
| **Inheritance**          | Requires inheritance.                    | Does not require inheritance.               |
| **Polymorphism**         | Achieves runtime polymorphism.            | Achieves compile-time polymorphism.         |

---

## **6. Rules for Method Overriding**

1. **Same Method Signature**: Name, return type, and parameters must match exactly.
2. **Access Modifiers**:
   - The overriding method cannot have a more restrictive access modifier than the overridden method.
   - Example: A `public` method in the superclass cannot be overridden as `protected` in the subclass.
3. **Static Methods**: Cannot be overridden, but can be hidden.
4. **Final Methods**: Cannot be overridden.
5. **Constructors**: Cannot be overridden.

## **7. Practical Example: Inheritance and Method Overriding**

### **Problem: Vehicle Hierarchy**

Create a vehicle hierarchy where different types of vehicles override a `start()` method.

**Solution:**
```java
class Vehicle {
    void start() {
        System.out.println("Vehicle is starting.");
    }
}

class Car extends Vehicle {
    @Override
    void start() {
        System.out.println("Car is starting with ignition.");
    }
}

class Bike extends Vehicle {
    @Override
    void start() {
        System.out.println("Bike is starting with a kick.");
    }
}

public class VehicleExample {
    public static void main(String[] args) {
        Vehicle myCar = new Car();
        Vehicle myBike = new Bike();

        myCar.start();
        myBike.start();
    }
}
```

**Output:**
```
Car is starting with ignition.
Bike is starting with a kick.
```

## **8. Best Practices**

1. **Use `@Override` Annotation**: Ensure the method signature matches exactly.
2. **Leverage `super` for Reuse**: Use `super` to avoid rewriting common logic.
3. **Follow Access Rules**: Maintain or increase the visibility of overridden methods.
4. **Encapsulate Common Features**: Place shared attributes and methods in the superclass.

---

## **9. Summary**

- **Inheritance**:
  - Allows a class to reuse and extend the properties and behaviors of another class.
  - Supports "is-a" relationships for hierarchical modeling.
- **Method Overriding**:
  - Enables subclasses to provide specific behavior for methods defined in the superclass.
  - Achieves runtime polymorphism.
- **Key Tools**:
  - `super` keyword for accessing superclass members.
  - `@Override` annotation for clarity and error prevention.

By mastering inheritance and method overriding, you can build modular, reusable, and maintainable Java applications that leverage the power of object-oriented programming.
