# **Classes and Objects in Java**

**Classes** and **objects** are the core building blocks of object-oriented programming (OOP) in Java. They enable developers to model real-world entities and their interactions in code. This chapter explains the concepts of classes and objects, their creation, usage, and best practices.

---

## **1. What is a Class?**

A **class** is a blueprint or template for creating objects. It defines the attributes (fields) and behaviors (methods) of an object.

### **Key Features of a Class**
1. Encapsulation: Combines data (fields) and behavior (methods).
2. Reusability: Can be instantiated multiple times to create objects.
3. Modularity: Groups related code together.

---

### **Syntax of a Class**
```java
class ClassName {
    // Fields (attributes)
    type fieldName;

    // Methods (behaviors)
    returnType methodName(parameters) {
        // Method body
    }
}
```

---

### **Example: Defining a Class**
```java
public class Car {
    // Fields
    String brand;
    int speed;

    // Method
    public void drive() {
        System.out.println(brand + " is driving at " + speed + " km/h.");
    }
}
```

---

## **2. What is an Object?**

An **object** is an instance of a class. It represents a real-world entity with state (fields) and behavior (methods). Objects are created using the `new` keyword.

### **Key Features of an Object**
1. Identity: A unique reference to the object in memory.
2. State: The values of its fields.
3. Behavior: The operations it can perform, defined by its methods.

---

### **Example: Creating an Object**
```java
public class Main {
    public static void main(String[] args) {
        Car myCar = new Car(); // Create an object
        myCar.brand = "Toyota"; // Set fields
        myCar.speed = 120;
        myCar.drive(); // Call method
    }
}
```

**Output:**
```
Toyota is driving at 120 km/h.
```

---

## **3. Constructors**

A **constructor** is a special method used to initialize objects. It has the same name as the class and no return type.

### **Default Constructor**
If no constructor is defined, Java provides a default constructor.

### **Parameterized Constructor**
A constructor that accepts parameters to initialize object fields.

**Example: Using a Constructor**
```java
public class Car {
    String brand;
    int speed;

    // Constructor
    public Car(String brand, int speed) {
        this.brand = brand;
        this.speed = speed;
    }

    public void drive() {
        System.out.println(brand + " is driving at " + speed + " km/h.");
    }
}

public class Main {
    public static void main(String[] args) {
        Car myCar = new Car("Honda", 100); // Use constructor
        myCar.drive();
    }
}
```

**Output:**
```
Honda is driving at 100 km/h.
```

## **4. Fields and Methods**

### **Fields**
Fields are variables that store the state of an object.

**Example:**
```java
class Person {
    String name;
    int age;
}
```

---

### **Methods**
Methods define the behavior of an object.

**Example:**
```java
class Person {
    String name;
    int age;

    public void introduce() {
        System.out.println("Hi, I am " + name + " and I am " + age + " years old.");
    }
}
```

---

## **5. Access Modifiers**

Access modifiers control the visibility of fields, methods, and constructors.

| **Modifier** | **Scope**                                                   |
|--------------|-------------------------------------------------------------|
| `public`     | Accessible everywhere.                                      |
| `private`    | Accessible only within the same class.                      |
| `protected`  | Accessible within the same package and by subclasses.       |
| Default      | Accessible within the same package.                         |

**Example:**
```java
public class Car {
    private String brand; // Accessible only within this class

    public void setBrand(String brand) { // Setter method
        this.brand = brand;
    }

    public String getBrand() { // Getter method
        return brand;
    }
}
```

---

## **6. Object-Oriented Principles**

### **6.1. Encapsulation**
Encapsulation bundles data and methods together and restricts access to them.

**Example:**
```java
public class BankAccount {
    private double balance;

    public void deposit(double amount) {
        balance += amount;
    }

    public double getBalance() {
        return balance;
    }
}
```

---

### **6.2. Abstraction**
Hides implementation details and shows only functionality.

**Example:**
```java
public class Calculator {
    public int add(int a, int b) {
        return a + b;
    }
}
```

---

## **7. Static Members**

Static fields and methods belong to the class rather than instances.

**Example: Static Field and Method**
```java
public class MathUtil {
    static double pi = 3.14159;

    public static double calculateArea(double radius) {
        return pi * radius * radius;
    }
}
```

---

## **8. Real-World Example**

**Example: Modeling a Library System**
```java
public class Book {
    String title;
    String author;

    public Book(String title, String author) {
        this.title = title;
        this.author = author;
    }

    public void displayDetails() {
        System.out.println("Title: " + title + ", Author: " + author);
    }
}

public class Library {
    public static void main(String[] args) {
        Book book1 = new Book("1984", "George Orwell");
        Book book2 = new Book("To Kill a Mockingbird", "Harper Lee");

        book1.displayDetails();
        book2.displayDetails();
    }
}
```

**Output:**
```
Title: 1984, Author: George Orwell
Title: To Kill a Mockingbird, Author: Harper Lee
```

## **9. Comparing Classes and Objects**

| **Aspect**        | **Class**                                   | **Object**                              |
|--------------------|--------------------------------------------|----------------------------------------|
| **Definition**     | Blueprint for creating objects.            | Instance of a class.                   |
| **Data**           | Defines the structure and behavior.        | Contains specific values of fields.    |
| **Memory**         | Does not occupy memory until instantiated. | Occupies memory.                       |

---

## **10. Best Practices**

1. **Use Meaningful Names**: Choose descriptive names for classes and objects.
2. **Encapsulate Data**: Use private fields with public getters and setters.
3. **Minimize Redundancy**: Use constructors and methods for repetitive tasks.
4. **Leverage Static Members**: Use static fields and methods for shared data or utility functions.

---

## **11. Summary**

- **Class**: A blueprint defining the structure and behavior of objects.
- **Object**: An instance of a class with specific attributes and behaviors.
- **Constructors**: Initialize objects with default or specific values.
- **Encapsulation**: Protects and organizes data and methods.

Understanding classes and objects is fundamental to mastering object-oriented programming in Java. By effectively using these concepts, you can create modular, reusable, and maintainable code.
